主管税务局

直接税管理机构（ACD）；增值税登记、域名及管理机构（AEDT）；综合电子申报门户：卢森堡我的服务门户（MyGuichet.lu）（https://myguichet.lu）。

电子政务申报门户

SCSp作为一种非公司形式的特殊有限合伙企业，在卢森堡所得税方面具有财务透明度，但在进行需缴纳卢森堡税的交易时必须办理增值税登记。未设立实体的经营者必须在首次征税活动之前，通过MyGuichet.lu向AEDT提交增值税登记申请。所需文件包括：合伙协议、RCS登记证明（如果SCSp已注册）、普通合伙人的身份文件以及企业设立证明。随后，AEDT会颁发一个卢森堡增值税识别号码（格式为LU后接8个字母数字字符）；ACD则使用RCS登记号用于公司税记录。

税号代号与申请路径: Pass_Through_Eligible — SCSp作为一种非公司形式的特殊有限合伙企业，在卢森堡所得税方面具有财务透明度，但在进行需缴纳卢森堡税的交易时必须办理增值税登记。未设立实体的经营者必须在首次征税活动之前，通过MyGuichet.lu向AEDT提交增值税登记申请。所需文件包括：合伙协议、RCS登记证明（如果SCSp已注册）、普通合伙人的身份文件以及企业设立证明。随后，AEDT会颁发一个卢森堡增值税识别号码（格式为LU后接8个字母数字字符）；ACD则使用RCS登记号用于公司税记录。

默认税务分类与身份选举

默认税务归类

Pass_Through_Eligible

支持身份选举表单

默认的财政透明性适用于SCSp；合伙人根据其各自管辖地分别征税。根据LIR第175条，合伙企业可在满足法定条件的前提下，选择作为企业纳税人进行征税。卢森堡的反混合规则（2018年12月21日转译ATAD的法律）对不匹配的透明实体进行重新定性，并在出现双重免税情形时取消相关优惠。不存在类似美国“查盒”制度；实体的分类依据卢森堡LIR的国内原则以及OECD关于合伙企业报告的指导文件。

流转税 (VAT / GST) 与出口 0% 零税率

标准增值税/流转税率

16%

强制登记营业额门槛 (Nexus)

对于未建立企业实体的纳税人，没有注册门槛：卢森堡境内首次提供应税服务时即需进行增值税注册。对于服务提供者而言，年度营业额不超过35,000欧元可享受国内小型企业免税优惠。欧盟内部商品销售及跨境B2C数字服务则需满足10,000欧元的统一标准，超过此标准的则适用OSS/IOSS制度。

跨境出口 0% 零税率申报条件

向第三国目的地出口有形货物可享受0%的增值税税率。对于人工智能/大语言模型API服务（电子形式的服务），适用供应地规则：面向非卢森堡客户的商业客户（B2B）供应，属于卢森堡增值税的境外交易（反向征税）；面向非欧盟消费者的个人客户（B2C）供应，属于卢森堡增值税的境外交易；面向欧盟消费者的个人客户（B2C）供应，则在消费者所属成员国通过OSS规则征税。服务的零税率认定，依据客户所在地、企业经营状况以及使用与享受情况的分析来证明，而非依赖物理海关清关手续。

  • 已执行的AI/LLM API服务协议，明确客户管辖权和服务交付条款
  • 欧盟境内B2B客户的经VIES验证的增值税识别号
  • 商业注册证明或同等的公司证明文件（针对非欧盟的B2B客户）
  • 正确填写供应地编码和增值税处理说明的税务发票
  • 汇入款项/外汇结算证明（SWIFT、Stripe或USDC链上记录），用于支持资金回流

卢森堡目前不实施实时财政结算、基于API的税务申报、数字印章制度，也不要求企业进行B2B电子发票开具。发票必须符合LGTVA第75条的内容要求；OSS/IOSS退税则通过AEDT管理的欧盟单一门户进行申报。预计“数字时代的欧盟增值税”计划将在2030年前为卢森堡的纳税主体引入强制性的电子发票开具和数字交易报告制度。

AEDT反欺诈部门（ULAF）和ACD审计部门可以质疑出口零税率及OSS相关安排。若相关主张无法得到支持，则会导致增值税重新评估、法定延迟利息以及罚款；而欺诈行为则会使相关实体面临刑事处罚（最高5年监禁和最高25万欧元的罚款），还会导致输入增值税抵扣款被追溯收回、判决结果被公开，同时可通过Eurofisc进行跨境情报共享。

外汇管制与央行政策诊断

经常项目兑换自由度

卢森堡是欧盟完全成员国；欧元可以在经常账户支付（如API订阅费、云托管费用、许可费用）和资本账户交易（如对SCSp的资本投入、利润分配及清算收益）中自由兑换。不存在外汇管制限制、兑换许可证或遣返许可。非居民合作伙伴可以无需BCL批准即可汇出合伙收益，但必须遵守欧盟的反洗钱/反恐怖融资尽职调查要求、税收透明度义务（如CRS、FATCA、DAC6等），以及欧盟/联合国制裁规定。对于具有税收透明度的SCSp，合伙收益无需缴纳卢森堡预提税，但银行可能会在处理汇款前要求提供最新的真实所有权声明及分配决议证明。

出口外汇强制结汇要求

卢森堡不要求将出口收入上缴，也不规定强制兑换比例或持有期限要求。以欧元或外币计价的AI LLM API服务所得收入，可以留在账户中、重新投资或转移到国外，无需获得BCL的同意。唯一的行政义务是根据欧盟国际收支条例（EC）第184/2005号进行统计分类，以及遵守BCL报告要求：基于软件提供的API服务收入应归类为“电信、计算机和信息服务”这一国际收支服务类别。没有规定具体的时间限制或兑换比例。

央行监管: 卢森堡中央银行（BCL），联合卢森堡财政部、金融监管委员会（CSSF）负责反洗钱/反恐融资监督，以及欧洲中央银行（ECB）负责欧元货币政策和国际收支统计报告。

离岸数字新锐银行 / EMI 白名单

Cross-border EMI / Fintech rails 适配度: High

可行性评级：对于未经监管的海外电子货币机构（EMI），评级为中等偏低；对于非欧洲经济区（EEA）的数字银行，评级为偏低。卢森堡法律允许使用经EEA许可的电子货币机构（EMI）进行支付处理，但已建立的一级卢森堡银行通常拒绝将EMI作为与非居民合伙人合作的合伙企业主要资金账户，因为EMI无法保证本地受益人反洗钱（AML）、制裁及经济实质方面的监管要求。一个可行的混合模式是：仅将经监管的欧盟EMI（例如，获卢森堡金融监督局（CSSF）/欧洲央行（ECB）许可的EMI）作为低价值的中间层，用于API客户结算流，而合伙企业的主要SCSp资金账户以及所有资本流动均需通过卢森堡商业银行处理。任何以加密货币为支撑的EMI或加密货币支付网关（如USDC/加密货币）必须与企业资金账户隔离，且仅当位于欧盟境内、符合反洗钱（AML）要求的支付服务提供商负责将加密货币兑换为法定货币，并将洁净资金划入银行账户时，方可用于客户开票。EMI的备用方案必须完成完整的银行KYC审核。
