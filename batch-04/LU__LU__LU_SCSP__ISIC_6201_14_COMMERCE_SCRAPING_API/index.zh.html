对于SCSp而言，没有法定的最低实收资本要求；资本数额完全由合伙协议确定。出资可以以现金、实物或行业资源的形式进行。根据卢森堡法律，无需设立托管账户；如果SCSp被授权为资产管理计划并受《资产管理计划法规》约束，则可以通过合同约定采用托管方式来完成交易。

注资与解冻路径: 商业办公空间的消防认证仅在员工人数超过100人或建筑被归类为高火灾荷载时才需要。对于标准办公用途，无需进行结构荷载检测。SCSp必须向劳动与矿业检查局（ITM）完成工作场所注册，并在投入使用前张贴疏散计划并提供急救包。办公场所的职业健康与安全许可通过向劳动与矿业检查局（ITM）提交办公场所声明获得。

对于相关数字服务（公共商业网络爬虫及代理API网关）：向非欧盟设立客户的B2B供应，根据一般供应地规则，应按客户营业地征税，从而在实际操作中实现卢森堡增值税率为0%，由客户自行评估并承担当地增值税。向欧盟客户的B2B供应则实行反向征税（依据卢森堡增值税法第58条），同样不属于卢森堡增值税的征税范围。面向非欧盟消费者的B2C电子服务，不处于卢森堡的地域征税范围之内。实物出口商品（例如服务器硬件或承载API服务的介质）在满足以下条件时，可适用卢森堡增值税法第42条规定的0%出口税率：即货物发运或运输至第三国目的地的手续在发运后90天内完成，并有相应证据；在欧盟内部的供应则需客户提供有效的欧盟增值税号码，并在汇总申报表中列明。在所有情况下，供应商必须保留至少10年完整的交付文件、收货方身份以及实际付款的证明。

  • 海关出口申报（单一行政文件/ EAD）——仅适用于实物商品，不适用于纯数字API服务
  • 提单/CMR/航空运单，证明将实物硬件或介质出口至第三国目的地

自2025年起，卢森堡不再实施实时连续交易控制、强制数字印章制度以及意大利式的清算系统。根据执行欧盟指令2014/55/EU的大公法令，强制电子发票制度仅适用于通过PEPPOL网络和UBL/BIS 3.0结构化格式进行的企业对政府供应业务。企业间电子发票制度仍属于可选选项，可以使用PDF、Factur-X/ZUGFeRD或UN/EDIFACT格式。发票必须保存10年；OSS返回文件以及客户位置相关证据（如IP地址、银行信息、注册国家证明、SIM卡、账单地址等）也需保存10年。

在标准的5年期限内，AEDT可以重新评估零税率或非正式提供的商品，在存在欺诈、伪造文件或不当安排的情况下，这一期限可延长至10年。如果遭到质疑，则须缴纳完整的17%卢森堡增值税，此外还需支付每月0.8%的逾期付款利息（每年9.6%）。根据卢森堡增值税法第63条，行政罚款每张发票可在250欧元到12,500欧元之间；如果出口商故意提交伪造的出口证明或隐瞒真实接收方，根据第64条，可能面临高达所逃税额两倍的刑事罚款及监禁处罚。如果数据传输服务通过人为结构进行安排，以掩盖真正的出口商或受益方，则出口商和总经理 може拥有共同责任。如果付款时间晚于180天，可视为销售被取消的证据，从而无法享受零税率待遇。

外汇管制与央行政策诊断

经常项目兑换自由度

在卢森堡境内，欧元可用于各种资本和经常账户交易。不存在法定外汇管制，盈利汇款也不需事先审批，对外来直接投资也无限制。由卢森堡应税实体支付的股息或利润分派可能需要缴纳卢森堡预提税，但SCSp税务透明机制所涉及的机构本身则无需缴纳预提税；外国合作伙伴则根据其所在国的税收规定来纳税。唯一的实际障碍来自欧盟/联合国制裁、反洗钱客户尽职调查要求，以及所有超过2,500欧元的现金支付必须通过信贷机构进行结算的要求。

出口外汇强制结汇要求

卢森堡没有关于出口收入上缴的规定，也不要求强制进行货币兑换。以外币持有的出口/API收入可以自由保留。然而，根据2017/01号BCL法规以及CSSF的报告要求，居民公司（包括SCsps）必须在特定日历月内报告超过50万欧元或等值金额的跨境交易，以便用于国际收支统计目的。未报告此类交易可能会面临行政罚款，但无需上缴或兑换外币。

央行监管: 卢森堡中央银行（BCL）在与欧洲中央银行（ECB）的欧元体系密切协调下运作；跨境资本流动的监管还由卢森堡金融监督局（CSSF）对金融行业参与者进行管理，并依据欧盟条约关于资本自由流动的规定（《欧盟条约》第63条）。

离岸数字新锐银行 / EMI 白名单

Cross-border EMI / Fintech rails 适配度: High

可行性：中高。根据PSD2规定，持有卢森堡牌照的电子货币机构（EMI）可提供完整的IBAN、SEPA和SWIFT接入服务，因此可作为资金管理的门户。然而，若无卢森堡或欧盟牌照的纯离岸EMI，则不能作为主要结算银行，因为卢森堡金融监督局（CSSF）要求支付机构必须在欧盟或欧洲经济区（EEA）国家获得授权。此外，针对USDC/USD的支付通道只能通过CSSF注册的虚拟资产服务提供商（VASP）进行集成，因为根据2004年11月12日卢森堡法律（经2019年8月15日法律修订），任何从事虚拟资产保管、交易或转移的实体均须取得VASP牌照。因此，推荐的金融科技架构为：（1）持有卢森堡牌照的EMI，用于法币的SEPA/SWIFT结算；（2）CSSF注册的VASP，用于受监管的USDC兑换；（3）内部记录系统，将每个数字钱包与法律实体及发票进行映射。

防御与化解材料: 一份合规控制说明，表明所有美元现金收入均通过瑞士金融监督局（CSSF）许可的虚拟资产服务提供商（VASP）进行流转，交易对手方钱包实时筛查美国财政部外国资产控制办公室（OFAC）及欧盟制裁名单，资金在1个营业日内兑换为欧元，并且每笔链上交易均以交易哈希和法律业务参考编号记录于财务台账中。

跨境清算通道与结算适配

所有境外合作伙伴的资本注入必须通过SEPA或SWIFT汇入SCSp在卢森堡/欧盟银行开立的专用欧元托管账户。付款参考应明确注明：（1）SCSp的商业名称和RCS编号（例如：“RCS Luxembourg BXXXXX”）；（2）付款用途为“向SCSp进行资本注入”；（3）一个适当的BCL国际收支编码（例如：“直接投资——股本资本”）。对于美元注入，须在SWIFT MT103报文第70栏中填写相同描述，并确保兑换银行为欧盟授权机构。任何超过欧元2,500的现金部分均属非法。当交易金额超过欧元50万欧元时，银行须进行资金来源核实，并在BCL统计报告（表PROC/IT）中记录该笔交易。贸易结算事项（如服务器基础设施、带宽、代理IP许可费）必须通过企业账户通过SWIFT MT103方式处理（用于跨境非欧元支付），或采用SEPA即时支付/SEPA直接扣款方式处理（用于SEPA区域内的欧元支付）。对于供应商融资，一种被商业界广泛接受的方式是由卢森堡银行为供应商开立的进出口信用证（UCP 600）；SCSp必须提供采购合同、形式发票以及保险证明。对于较小的定期API供应商费用，通过关联的EMI方式使用卡 rails（Visa/Mastercard）是允许的。如果供应商要求，USDC出账支付必须仅通过CSSF注册的VASP进行，且每次转账都必须附带包含发票编号、钱包地址以及智能合约哈希值的财务文件。直接交割的外汇远期合约（欧元/美元、欧元/英镑、欧元/瑞士法郎），交易对手为经欧盟或卢森堡授权的信用机构，双边交易需符合EMIR报告要求。对于较难兑换货币（如人民币、印度卢比）的非交割远期合约（NDFs）被允许用于贸易现金流对冲，且须依据2002年ISDA主协议并附有信用支持附件进行记录。外汇远期互换（期限不超过一年）用于对欧元和美元流动性头寸进行临时隔离管理，若以担保品进行担保，则在担保协议（CSA）或担保抵押协议（GMRA）下记账。交叉货币利率互换（CCIRS）仅限于承诺的融资设施及中国国家战略性产业基金（SCSp）长期资本支出的对冲，且仅与标准普尔评级至少为A-的银行签订。仅在以全额期权费预先支付的前提下，方可采用欧洲式货币期权进行基于费用的风险管理；若由SCSp出售此类期权，则必须事先获得银行单独批准的衍生品政策。

电商与网关结算适配度: 可行性：中高。根据PSD2规定，持有卢森堡牌照的电子货币机构（EMI）可提供完整的IBAN、SEPA和SWIFT接入服务，因此可作为资金管理的门户。然而，若无卢森堡或欧盟牌照的纯离岸EMI，则不能作为主要结算银行，因为卢森堡金融监督局（CSSF）要求支付机构必须在欧盟或欧洲经济区（EEA）国家获得授权。此外，针对USDC/USD的支付通道只能通过CSSF注册的虚拟资产服务提供商（VASP）进行集成，因为根据2004年11月12日卢森堡法律（经2019年8月15日法律修订），任何从事虚拟资产保管、交易或转移的实体均须取得VASP牌照。因此，推荐的金融科技架构为：（1）持有卢森堡牌照的EMI，用于法币的SEPA/SWIFT结算；（2）CSSF注册的VASP，用于受监管的USDC兑换；（3）内部记录系统，将每个数字钱包与法律实体及发票进行映射。

企业所得税 CIT、税表逐栏拆解、股息预提税 WHT 与董事个人法律穿透责任。

法定所得税率 (CIT)

24.94%（合计最高限额为17%的企业所得税加上7%的 solidarity附加税及卢森堡市商业税，卢森堡市适用税率；实际的企业所得税税率分别为：不超过175,000欧元的部分为15%，超过部分为17%，不包括市税）。根据卢森堡《公司法》第175条，特殊合伙企业（SCSp）在税务上具有透明性：合伙本身不缴纳卢森堡的企业所得税、商业税或净资产税；各合伙人直接对其分配利润份额纳税。非居民公司合伙人仅就归属于卢森堡常设机构的卢森堡来源利润缴纳卢森堡企业所得税。

股息预提税 (WHT)

15% 是适用于视为符合条件的分配的卢森堡境内股息预提税税率；然而，由于股份公司（SCSp）在税务上具有透明性，只要股份公司未选择完全适用企业所得税（CIT）征税，利润分配将不被视为股息。如果股份公司仍被视为在合伙人手中为卢森堡税收居民企业，则将适用法定15%的预提税，但可依据税收协定及欧盟母公司-子公司指令获得减免（对于符合资格的欧盟/欧洲经济区企业合伙人，若持股比例至少达10%且持续满12个月，减免为0%）。

转让定价与经济实质

主文档/本地文档门槛: 总额达45万欧元的受控关联方交易，需根据卢森堡转让定价文件规则提交卢森堡本地文件和汇总文件；若关联方位于非合作司法管辖区，则单笔交易或累计暴露金额超过10万欧元时，需达到10万欧元的门槛，并须保留同期基准对照研究。对于公共商业网络爬虫API业务，必须记录API网关访问和数据转售分成收入的独立交易毛利率。

经济实质审查范围: 卢森堡没有制定单独的《经济实体规定》；相关实体要求已融入《ATAD一般反滥用规则》（LIR第6条）、《法律滥用原则》（LIR第56条）以及OECD/G20 BEPS标准中。任何获得欧元级别API商业收入的SCSp，必须具备真实的实体要素：如位于卢森堡的办公场所、具备资格的当地管理及技术人员、在卢森堡作出的董事会决策，以及活跃的银行账户。企业合作伙伴和董事必须证明SCSp属于真正的商业项目，而非空壳机构，以避免被重新分类或失去条约优惠。

致命合规红线与董事个人责任

逃税及故意漏报

法定制裁: 重新评估适用总额24.94%的税率；处以250欧元至50,000欧元的税务欺诈罚款；逾期付款利息按每月0.6%计算；根据LIR第397条，故意逃税者将被判处8天至5年的监禁。

董事个人责任: 签署虚假报表的普通合伙人董事需对未支付的所得税承担共同和个别民事责任，根据《卢森堡一般税法》第397条还需面临刑事起诉、旅行禁令以及资产冻结等处罚措施，并会被取消董事资格。
空壳公司 / 人为安排 / 虚化行为

法定制裁: 忽略《LIR第56条》中的SCSp（滥用法律）；利润重新归于卢森堡的母公司；处以10%的滥用处罚；根据OECD主要目的测试拒绝享受税收协定优惠；以及因未披露可报告的跨境安排，根据DAC 6处以25万欧元的罚款。

董事个人责任: 董事可能就税务追偿承担连带责任，但若协助逃税将面临刑事处罚；若隐匿资产，则可能面临洗钱条款下的五年监禁风险；在税务追缴程序中，还可能被实施个人旅行禁令。
转让定价不当定价

法定制裁: 根据LIR第56(3)条进行主要TP调整；次级现金调整；对上调部分处以10%的罚款；逾期利息按每月0.6%计算；且不得扣除支付给SCSp的任何非独立交易费用。

董事个人责任: 签署集团内部协议的董事，若SCSp破产，需就额外税款承担个人民事责任；若伪造转让定价文件，则需承担刑事责任。
反洗钱/了解你的客户/受益所有权未达标

法定制裁: 根据2004年11月12日修订的卢森堡反洗钱法，罚款最高可达500万欧元，监禁时间为3个月至5年；RBE制度则对未提交或虚假的BO申报行为处以最高125,000欧元的行政罚款。如果支付活动需要支付机构许可证，卢森堡CSSF可以实施单独的执行处罚。

董事个人责任: 董事对反洗钱违规行为将承担个人刑事责任，可能面临罚款、被罢免董事职务、被禁止出境以及涉案资产被没收；使用无许可的支付渠道也可能导致对董事发出禁止令。
