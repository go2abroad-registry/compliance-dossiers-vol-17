税收免税区。根据RMI法律，那些既不在共和国境内开展业务，也不在共和国境内持有资产或财产的非居民国内企业公司，根据《企业公司法》第222条的规定，可依法免除所得税、总收入税、预扣税、资本收益税以及所有其他RMI税或费用，但年度报告/注册费除外。RMI的征税范围以地域和来源为基础：只有来自RMI来源的收入才需缴纳税款，例如3%的总收入税或2%的海上租船税下的当地企业总收入。非RMI子公司产生的被动股息、利息和资本收益则完全不属于RMI的征税范围，可以累积或重新分配，无需缴纳RMI税。

支持身份选举表单

RMI没有选择式选举机制，也没有CFC归属制度或混合不匹配相关法规；对于非居民国内企业来说，税收豁免是自动适用的，无法转化为通过选举方式获得的待遇。企业可以通过在共和国境内开展业务或收购RMI境内的资产来实际上“选择”成为RMI的税务居民，从而承担总收入税和工资支付义务。为了确保行政上的确定性，SPV可以自愿向RTA注册，并获得非居民身份/豁免证明。RMI通过RTA参与CRS和FATCA IGA下的信息自动交换，并受欧盟行为准则小组对透明度和合规性的监督；根据这些承诺所采取的任何经济相关或申报义务，都应在每次提交周期中与注册代理进行核实。

流转税 (VAT / GST) 与出口 0% 零税率

标准增值税/流转税率

马绍尔群岛共和国不征收增值税、GST或销售和使用税。唯一的间接税收包括根据《2005年海关关税法》所征收的海关进口税，以及各类行业总收入类型的税收——其中一般商业业务适用3%的税率，海上租赁服务则适用2%的税率。纯粹的股权持有型SPV则无需缴纳任何间接税，因为它在马绍尔群岛境内既不进口商品，也不提供任何服务。

强制登记营业额门槛 (Nexus)

由于没有增值税/ GST制度，因此不存在增值税注册门槛（统一税率为0%）。从海关角度来看，任何进口商都必须向海关和边境控制部门登记进口商代码，并按标准从价税率缴纳进口关税（通常介于0%至10%之间，大多数商品适用5%的统一税率），税款以美元支付（美元是RMI的法定货币）。3%的总收入税仅适用于在RMI内开展贸易或业务的人士，因此对于没有来自RMI的收入、只是持有海外股份的非经营性实体则不适用。

跨境出口 0% 零税率申报条件

不适用。由于不征收增值税/GST，因此没有法定的0%出口税率，也没有输入增值税退款机制，更不存在出口退税制度。SPV的海外股息和处置收益属于非RMI来源的收入，在收到时无需缴纳税款，因此无法提出退款请求。从RMI出口的商品免交出口关税，发票上也不包含任何增值税项目，出口商也没有相应的退款权利。与SPV相关的唯一证据就是董事会会议记录、股份登记册以及银行转账记录，这些都能证明其被动持有地位以及资金的非RMI来源。

  • 海关出口申报（CBCS/ASYCUDA World）——不适用于仅以股权持有为目的的特殊目的公司（SPV），此类公司不将货物运出密克罗尼西亚联邦（RMI）
  • 提单或运输单据——不适用；特殊目的实体（SPV）未从事ISIC 6420 / NAICS 551112所列的商品或航运活动
  • 汇入汇款证明文件/SWIFT MT103或MT202报文，证明收到境外股息及资金来源非RMI——保存于银行反洗钱/客户身份识别及CRS自我声明文件中
  • 由公司注册官签发的良好状态证明及非居民身份证明（根据《银行法》第222条豁免）——保留以证明不存在任何RMI税款责任

RMI法律并未规定必须采用电子发票制度，也不要求实时办理税务发票手续，更不要求商业发票需使用数字税票。不过，海关清关则是必须的，并通过ASYCUDA World单一窗口申报系统实现完全电子化操作：所有进出口货物在放行前都必须进行电子申报、估价和关税计算。SPV则不会开具属于RMI征税范围的发票，也不会搬运任何货物，因此既无需遵守电子发票规定，也无需履行海关清关义务。

由于无需缴纳出口税或增值税，因此不存在出口零关税欺诈或追回资金的相关机制。主要的合规风险包括：(i) 因在RMI开展实际业务活动或拥有RMI资产而失去第222条的豁免权，从而需对收入或总营收缴纳追溯性所得税；(ii) 注册机构因未按时提交报告而面临的罚款以及因未支付年度报告费用而导致的机构解散；(iii) 根据2014年税收与税务管理法，对虚假申报或逃税行为处以经济处罚和监禁；以及(iv) 若未能按照中等风险加强型反洗钱标准保存商业实体文件，则面临银行及反洗钱方面的后果，包括账户冻结和账户终止。目前没有外汇管制措施，也没有法定的外汇回流期限；以美元计价的经济体系允许无限期地保留股息收益于境外，但作为审计准备的最佳做法，应遵守180天的收入转汇周期。

外汇管制与央行政策诊断

经常项目兑换自由度

美元是法定货币，没有独立的国内货币，因此不存在资本账户与经常账户转换的限制。利润汇出、股息分配以及集团内部资金转移无需面对任何外汇转换障碍，也无需遵守外汇管制相关法规；唯一的合规要求包括反洗钱/反恐怖融资记录保存、受益权披露，以及跨境支付时符合美国OFAC的制裁规定。

出口外汇强制结汇要求

由于该地区没有国家货币体系，也没有规定的移交期限或强制兑换比例，所有收入均以美元计价。出口收益可以自由保留在以美元计价的账户中，无需向中央银行报告或履行汇回义务，不过对于所有现金或电汇交易来说，仍需遵守反洗钱/反恐怖融资的相关规定。

央行监管: 马绍尔群岛没有本土中央银行；货币监管工作由财政部下属的银行专员负责，并与金融行动小组合作进行。由于美元是自由联合协定下的唯一法定货币，美国联邦储备系统便充当了实际的货币管理机构。

离岸数字新锐银行 / EMI 白名单

Cross-border EMI / Fintech rails 适配度: High

评分：中等。如果离岸数字EMI能够通过美国或区域清算银行维持以美元计价的代理银行关系，那么其运作是可行的；不过，马绍尔群岛并不颁发国内EMI许可证，因此离岸EMI需依据其所在国的许可证进行运营，可被视为第三方支付处理商。法律限制包括FATF灰名单相关的监管要求、EMI必须与持牌银行建立相应的转拨关系，以及对结构化SPV的最终股东和受益人情况进行更严格的尽职调查。

跨境清算通道与结算适配

合规流程：（1）股东通过SWIFT MT103或MT202从母公司账户向马绍尔银行或美国代理银行的SPV运营账户汇款；（2）付款目的代码必须与股权认购相匹配——在美国美元清算中，联邦储备系统报告分类应根据实际情况选择“股权资本”或“集团内部融资”；（3）每次资金注入均须附带董事会决议、股份发行证明以及注册代理出具的资金到账函；（4）对于超过10万美元的资金注入，银行将在KYC文件中要求提供资金来源声明；（5）由于美元为本位货币，无需进行外汇兑换，因此不会触发中央银行兑换申报。主要清算渠道：(a) SWIFT MT103直接往来电汇，用于集团内部贷款支付、财务结算以及以美元进行的贸易付款；(b) 由美国或区域确认银行开立的商业信用证（跟单信用证），用于跨境采购结算，且卖方要求有付款担保；(c) SWIFT MT940/MT942余额报告，用于日常流动性核对；(d) 通过美国代理银行进行ACH支付，适用于低额且定期的支付，只要时间允许即可。所有对外指令必须包含符合ISIC标准的用途代码以及SPV的法律实体识别信息，以便进行核对。美元/美元的普通远期合约没有必要且实际上无法获得，因为当地货币不存在；对冲仅适用于子公司集团的非美元功能货币敞口。交叉货币远期合约（欧元/美元、英镑/美元、日元/美元）仅限于用于对冲运营子公司在SPV作为资金中心情况下所确认的特定应收或应付款项。仅当相关交易结算无法在境内完成清算，且NDF是由持牌国际银行根据ISDA主协议执行的时，才允许使用受限新兴市场货币的非可交付远期合约。允许以美元计价的利率互换对SPV在集团内部浮动利率债务上的敞口进行对冲，前提是该操作符合董事会批准的财务政策，并且存在经认可的双边净额结算主协议。货币期权是被允许的，但必须附带信用支持附件，并具备特定的对冲理由，以避免在银行合规审查中被归类为投机行为。

转让定价与经济实质

主文档/本地文档门槛: 在RMI中则无需缴纳企业所得税，也没有关于本地文件或主文件阈值的相关国内转让定价法规。外国集团实体在其所在税务管辖区仍需履行转让定价文档提交义务；常见的触发阈值包括5000万美元的合并收入，或超过100万美元的关联方交易，具体取决于母公司的税收规定。

经济实质审查范围: RMI并不为被动的纯股权控股SPV设立类似BVI/开曼式的经济实体注册制度。不过，法定税收减免的前提是该公司必须是非居民企业：该公司在RMI中不得从事任何商业活动，且其管理和业务职能必须位于海外。SPV还必须设立注册办公室、注册代理人、董事会会议记录、法定账簿以及准确的会计记录。在外国税收和反洗钱调查中，如果没有实际的所有权控制、银行账户分离或明确的股息政策，就会被视为空壳公司的警示信号，可能导致调查深入调查。

致命合规红线与董事个人责任

逃税 / 伪造非居民身份申报

法定制裁: 失去非居民税收豁免权；在适用情况下需承担来自RMI的收入征税责任；登记处实施的行政处罚；在RMI法院因虚假陈述而面临刑事起诉，可能面临罚款和监禁。

董事个人责任: 签署或批准虚假声明的董事，可能需就该实体未缴税款及罚款承担个人责任，可能被禁止在RMI担任董事，并可能因欺诈行为被处以刑事罚款和监禁。
空壳公司 / 缺乏经济实质

法定制裁: RMI注册代理可以辞职，注册处可以行政上解散该机构，外国往来银行可以终止Swift支付和银行间通道连接，而RMI金融情报部门或外国监管机构则可以冻结资产以等待调查。

董事个人责任: 法院在特殊目的实体仅为工具性安排的情况下，可以穿透公司法人面纱。董事可能被责令返还被挪用的公司资金，若其涉及上游犯罪调查，可能被实施旅行禁令，并在利用空壳结构实施欺诈的情况下被判处监禁。
反洗钱/了解你的客户及受益所有权违规

法定制裁: RMI AML法规要求注册代理人向RMI金融情报部门报告可疑活动。不保守秘密的行为可能导致经济处罚、资产冻结、企业资产没收、注册代理执照被撤销，以及根据RMI刑法承担刑事责任。

董事个人责任: 明知参与洗钱活动或隐瞒实际受益人者，将面临个人刑事责任、资产没收、旅行限制及监禁。对于犯罪行为，公司法人屏障不予适用。
转让定价 / 假冒关联交易文件

法定制裁: RMI没有企业税负担，但外国母公司司法管辖区可能会重新界定该架构，禁止扣除项，实施转让定价处罚，并利用BC的会计记录作为法医证据；RMI的企业记录则可通过相互法律协助被调取。

董事个人责任: 签署虚假协议或假发票的董事可能面临民事共谋责任、外国司法管辖区的罚款、发票欺诈的刑事指控，以及在跨境案件中被引渡的风险和旅行禁令。
