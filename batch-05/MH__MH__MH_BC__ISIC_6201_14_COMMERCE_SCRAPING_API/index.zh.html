法定注册代理人与物理地址 强制持牌代理

在这一风险等级下，允许的做法是：每个马绍尔群岛企业公司必须在马绍尔群岛共和国的持牌注册代理处设立注册办公室，且该注册代理须依据《2004年注册代理法》获得许可，以处理各种法律文件。无需设立实体办公场所、当地员工或当地董事，该实体也可以完全通过远程方式运营。因此，所谓的“虚拟办公室”只能作为注册代理的实体注册办公室来使用，而非单纯的邮件转寄地址。像Stripe这样的第三方支付处理器所要求的第三方KYB认证以及公司身份和股东信息文件，属于平台要求，并非马绍尔群岛商业登记局对ISIC 6201活动所规定的法定要求。

现行法典依据

马绍尔群岛共和国商业公司法，1987年版（经修订）（B.C.A.）——第二部分（公司设立）、第三部分（注册办事处和注册代理人）；以及在设立实体物理存在后，由《注册代理人许可法》和《外商投资业务许可证法》补充规定。

法定实缴资本与验资锁资账户流程 强制验资锁定

非居民企业无需遵守法定的最低注册资本或授权资本要求；股份可以按董事会确定的任何合法对价发行（1美分面值即可），且无需进行托管、存款或资本维护账户管理。

注资与解冻路径: 对于纯粹的离岸实体来说，此要求并不适用；具体取决于现场需求，因为物理基础设施需要由相关机构负责：RMI消防安全检查证书（民防许可）、架式设备的结构载荷认证，以及根据RMI职业健康标准对任何员工进行的职业健康许可。

实缴资本规则: 非居民企业无需遵守法定的最低注册资本或授权资本要求；股份可以按董事会确定的任何合法对价发行（1美分面值即可），且无需进行托管、存款或资本维护账户管理。

决定：许可注册代理在马朱罗的办事处应被确认为公司的法定注册办公室和代理机构。

决定：由创始董事指定的主席、秘书和财务主管应被任命为官员，他们有权开设银行账户、签署合同，并办理非居民免税身份相关文件。

决定：应发行股票证书，所有年度注册文件均由这些官员负责处理。

外汇管制与央行政策诊断

经常项目兑换自由度

美元是唯一的官方货币和法定支付手段。RMI政府没有实施任何外汇管制法律、资本账户限制或经常账户限制。资本投入、股息、利息、服务费用以及清算所得都可以自由以美元或任何允许使用的外币进行汇出。实际限制仅出现在银行和同行银行层面，通过反洗钱/客户身份识别审查、OFAC制裁过滤机制以及资金来源验证来产生。非居民企业无需办理利润汇出许可或获得银行监管官的事先批准。

出口外汇强制结汇要求

马绍尔群岛没有关于必须上交出口收益的法定要求。没有强制性的兑换比例，也没有规定必须将出口收益或所得收入兑换成美元或存入当地银行的时间限制。非居民BC可以自行决定将出口收益以美元或外币形式存放于自己的账户中，但须遵守其持牌商业银行的账户条款。

央行监管: 马绍尔群岛共和国银行监管官（财政部）；马绍尔群岛没有本国中央银行，美元计价的流动性由美国联邦储备系统货币政策管理。

转让定价与经济实质

主文档/本地文档门槛: 0美元——没有法定的转让定价文件，根据RMI法律，非居民BC者也不适用本地文件/主文件制度。实际门槛是RMI的信誉和谨慎标准：需保持同时存在的合同、定价表以及与ESR申报和银行KYC审核相兼容的财务记录。

经济实质审查范围: 《经济实体规定》从2024财年起，为从事相关活动的RMI注册实体制定了“实体优先于收入”的原则。被归类为分销和服务中心的网络抓取/代理API网关必须证明具备RMI的管理与控制能力、足够的RMI员工及办公场所，且收入符合规定标准；除非其能够合法证明自己属于外国税务居民，否则将被视为需要报告的企业实体，从而让企业的伪装面暴露出来。

致命合规红线与董事个人责任

逃税 - 伪造非居民申报

法定制裁: 将BC重新分类为RMI税收区域：需缴纳3%的总收入税及利息；可能面临高达50%的罚款；登记机构可以将BC从企业登记册中删除；该实体将失去良好信誉，也无法使用RMI法院的服务。

董事个人责任: 签署虚假声明的董事需就已征收的税款、罚款及费用承担连带和按份责任；欺诈性虚假陈述不仅可构成刑事犯罪，最高可被判处五年监禁，并可揭开公司面纱，使股东和董事面临直接的个人追偿。
空壳公司 / 经济实质违反

法定制裁: ESR罚款金额为1万美元；每日违约罚款为1000美元；故意虚假陈述的罚款将逐步提高至5万美元；列入注册机构的不合规名单，并导致该银行及其代理行账户被冻结；最终撤销其注册。

董事个人责任: 董事、高级管理人员及注册代理人因基于其指示导致违约而需承担个人处罚责任；注册官可取消其未来担任董事的资格，实施旅行禁令作为执行担保，并穿透空壳公司，使其个人资产承担RMI注册罚款责任。
反洗钱/洗钱上游犯罪（中风险增强）

法定制裁: 违反RMI洗钱控制法及AML/CFT法规：可处以最高100万美元的刑事罚款，或相当于所洗钱金额两倍的罚款；也可处以最高10年的监禁；金融监管机构或注册机构可以冻结Stripe结算余额和USDC地址，并取消该公司的注册资格。并将该实体及其相关方列入财务行动清单中。

董事个人责任: 参与或从中获益的董事将面临洗钱罪的刑事责任、民事没收、红色通缉令或护照级别旅行禁令、被引渡至对方司法管辖区的风险，以及公司仅是主要股东的工具性实体，因此可被揭开公司面纱。
欺诈性转让 / 资产剥离

法定制裁: RMI欺诈性转让原则：撤销并追回相关转让行为，恢复债权人对该实体的债权；董事违反《商业公司法》规定的信托责任，需对非法分配行为负责。

董事个人责任: 对董事的民事追偿令；要求董事会成员偿还非法分配款项的价值；在严重情况下，法院可穿透公司外壳，并追究股东行为，允许在全球范围内执行资产查封。
