RMI法律中不存在美国式的勾选式分类选举制度。现有的法定选举与状态机制包括：(1) 非居民企业身份——公司章程可声明该企业为非居民企业，从而根据1989年所得税法自动减少因RMI相关活动而产生的税务负担；(2) 国际实体免税身份选择——向RTA/财政部提交正式申请，以获得符合条件的国际实体的法定免税地位（例如，根据RMI海事法从事的国际航运业务以及根据国际银行法从事的国际银行业务）；(3) 企业形式选择——企业创始人可以选择将企业注册为BC、LLC、有限合伙企业或有限期限公司，每种形式都会产生不同的外国税收分类情况；(4) 混合不匹配情况——RMI尚未制定OECD BEPS行动2中的国内混合不匹配规则，因此没有混合工具、混合实体或分支机构不匹配的选择选项；依赖外国实体分类的纳税人必须根据一般的领土来源规则自行评估。

流转税 (VAT / GST) 与出口 0% 零税率

标准增值税/流转税率

无增值税/GST的混合间接税制度：（i）根据《进口关税法》及《海关条例》（从价关税表）征收的进口关税；（ii）根据1989年《毛收入税法》征收的毛收入税（GRT），税率为来源于RMI的毛收入的3%。向非居民买家出口制造商品的销售不计入毛收入，实际相当于零税率；不存在增值税进项抵扣或退税链条，进口原材料用于出口商品时的进口关税减免，通过海关进境加工/关税减免规定予以处理。

强制登记营业额门槛 (Nexus)

官方货币：美元（USD），即RMI的法定货币。业务许可与注册：任何开展RMI相关业务的企业，当其预计或实际年度总收入达到10,000美元的最低标准时，必须进行注册；低于该标准的，则只需办理简单的许可手续即可。对于没有RMI相关收入的非居民BC企业来说，则无需满足任何标准。由于尚未制定相关增值税/ GST法规，因此也没有增值税注册标准。

跨境出口 0% 零税率申报条件

出口实际零税率的资格标准如下：（1）所涉商品（根据ISIC 3250分类的超高清4K微创刚性内窥镜及腹腔镜手术塔组件）必须通过与位于密克罗尼西亚联邦（RMI）境外的买方签订合同进行销售，且所有权和风险转移须发生在RMI领土之外；（2）销售所得款项必须以美元或其他外币自非居民来源收取，且不包含任何源自RMI境内的收入成分；（3）若组件被进口至RMI，并在组装成完整手术塔后重新出口，进口商须在进口时申请内销加工/关税减免待遇，并保存工厂流转记录；（4）在RMI境内为非居民客户提供服务，仅当其利益完全在境外实现时，方可享受GRT排除待遇；（5）BC须持续维持其非居民身份声明，若经审计，须通过董事会会议记录和管理层所在地记录证明其未在RMI设立常设机构。

  • 海关出口申报（RMI海关出口单据需注明出口商/托运人注册代码）
  • 商业发票及详细的装箱单（按顺序编号，并与实物库存记录一致）
  • 提单或承运人/中性空运提单，证明货物的离岸目的地及所有权转移
  • 汇入证明或银行SWIFT付款通知，证明在汇回期限内已收到出口收入
  • 经认证的公司设立证书及非居民身份声明（如持有营业执照及GRT排除证明，应附上）
  • 原产地证明或申领保税区或再出口减免税待遇所需的海关保税/退税文件

没有国家层面的电子发票或实时税务清算要求：没有电子发票标准，也没有 SAF-T/PEPPOL/XML 发票格式、数字税章制度，也没有清算 API 或税务设备认证机制来规范商业发票。纳税人必须开具序列号发票，并保留符合法定保存期限的账簿和记录。对于实物出口，RTA海关部门要求通过其内部海关清算平台提交电子海关出口声明；该文件属于贸易控制文件，不能替代税务发票的清算流程。

RTA可能会在法定时效期内重新处理出口申报事项（7年；若被认定存在欺诈行为，则不受限制）。如果某项出口销售被重新归类为RMI来源收入，RTA将按发票总额计算3%的GRT，并按公布的月利率加上法定利息进行核算，同时处以不超过少缴税款50%的民事罚款。参与虚假或欺诈性文件的行为将根据1989年所得税法面临刑事起诉（罚款和/或监禁最高5年），同时还可能面临海关处罚，包括货物被没收、财产被充公以及最高可达货物价值或逃税金额之高的行政罚款。那些故意出具虚假零税率或出口文件的注册代理和企业官员将承担个人责任，其执照将被撤销，且纳税人可能需要在进一步出口得到批准之前缴纳海关保证金。

外汇管制与央行政策诊断

经常项目兑换自由度

美元是唯一的法定支付手段，RMI不实施任何外汇管制法规。经常账户和资本账户交易均可完全兑换且不受限制：对股息、利息、贷款偿还或资本削减或清算所得的资金汇出没有法律上的限制。不在RMI境内从事贸易或业务的非居民企业可免交所得税和总收入税，RMI也不征收股息预扣税；因此，唯一的实际障碍就是银行自身的制裁审查及反洗钱审查，而非RMI的法规规定。

出口外汇强制结汇要求

没有。RMI不设定任何法定时间限制，也不要求达到最低转换比例或必须上交出口收益。应收款项可以保留为美元或任何允许使用的外币，由不列颠哥伦比亚省政府根据自行决定在境内经RMI许可的银行或境外银行进行存储。不过，该实体仍需保存完整的交易文件（商业发票、提单、信用证或MT103记录），以满足银行对持续交易的监控要求，并支持其非居民免税身份。

央行监管: 马绍尔群岛共和国没有中央银行。官方法定货币为美元；因此，货币政策和货币可兑换性条件由作为流通货币发行机构的美国联邦储备系统负责管理。银行许可和审慎监管工作则由财政部的银行专员根据1991年银行法来执行；反洗钱/反恐怖融资监管则由隶属于总检察长办公室的金融情报机构负责。

离岸数字新锐银行 / EMI 白名单

Cross-border EMI / Fintech rails 适配度: High

可行性评级：较低。根据1991年银行法，马尔代夫没有电子货币机构（EMI）的许可制度，且非居民企业公司并未被法律禁止在外国金融科技银行开设账户。然而，在实际操作中，信誉良好的欧盟、英国及亚太地区的电子货币机构通常将马尔代夫的免税商业公司归类为离岸或空壳风险类别，并因下游美国代理银行的风险规避政策而普遍拒绝为其开户。若可获得，金融科技账户通常为非信贷、仅限支付的电子钱包，交易限额严格，且不具备任何贸易融资的文件支持功能。法律限制：任何境外电子货币机构必须在其本国完全获得授权，同时马尔代夫实体仍需向该电子货币机构的合规部门提交受益所有权声明、资金来源证明以及董事会决议。

转让定价与经济实质

主文档/本地文档门槛: 马绍尔群岛没有关于内部转移定价的法律规定，也不设定本地文件或主文件方面的限制标准。不过，对于非居民制造的特殊目的公司而言，当企业间跨境交易每年超过50万美元时，建议进行公平交易式的文档记录，以便证明不存在M.I.应税存在，并避免被本国税务机关重新认定。

经济实质审查范围: 马绍尔群岛对从事“相关活动”的实体实施经合组织规定的经济实质法规。手术内窥镜的生产并不属于上述相关活动，因此非居民企业无需经过经济实质测试。不过，这些企业必须设立注册代理机构并提交年度企业报告；董事们必须能够证明中央管理权是在马绍尔群岛之外行使的，以避免出现关于国内税务居住地的争议。

致命合规红线与董事个人责任

逃税 / 误用免税地位

法定制裁: 根据1989年马绍尔群岛所得税法及1990年商业公司法，故意提交虚假免税声明属于犯罪行为，可处以最高25,000美元的罚款和/或最高5年的监禁。财政部也可以追溯将该实体重新认定为居民企业，并按营业收入的3%征收所得税，利息则按每月2%的利率计算。

董事个人责任: 签署虚假声明的董事需就未缴税款及罚款承担个人责任，责任金额最高不超过应缴未缴总额。注册官可对其实施旅行禁令，并将案件提交总检察长以启动刑事没收程序；若涉及等效的外国逃税行为，可依据相互法律协助条约触发引渡。
空壳公司 / 缺乏经济实质

法定制裁: 尽管制造活动不在列出的ESR相关业务范围内，金融行动特别工作组（FATF）和全球论坛可能要求注册代理人终止客户关系，以防止壳公司被用于协助税务犯罪。当地法律允许注册机构将公司从注册名单中除名；若被认定为“严重违约”，可能面临50万美元的罚款。

董事个人责任: 董事明知地允许公司被用作虚假实体，将就外国税务评估、民事追偿令及资产冻结令承担连带及单独责任；马绍尔群岛高等法院可发出此类命令。该董事可能被列入该国旅行制裁名单，直至其配合国际税务调查为止。
反洗钱/反恐融资违规

法定制裁: 根据2022年反洗钱和打击恐怖主义融资法，金融机构和非金融机构必须报告涉嫌洗钱行为。未能遵守规定的个别公司将面临最高达100万美元的民事处罚；董事和高管则可能面临最高达25万美元的刑事罚款以及最高10年的监禁。

董事个人责任: 董事及高级管理人员因未实施了解客户（KYC）和受益所有人控制措施而需承担个人责任。金融情报单位可对个人实施旅行禁令、冻结个人及婚姻财产，以及禁止其未经许可离开本国。在严重情况下，还可能被引渡或在国外被起诉。
转移定价欺诈 / 利润汇回骗局

法定制裁: 马绍尔群岛没有国内的税收法规，但根据OECD/G20包容性框架的多边机构规定，该岛的司法管辖区可能需要进行跨境税务审计合作。根据外国税法，虚假特许权使用费安排可以被重新认定，从而导致扣除项被拒绝，并面临调整后收入的50%的罚款。当地官员还可能因虚假声明该实体可免税而面临伪证罪指控。

董事个人责任: 签署虚假关联交易协议的董事及影子董事可能就外国税款不足承担个人责任；已有判例穿透公司人格，对相关人员实施旅行禁令并没收个人奖金。根据《防止欺诈（M.I.）法案》，任何因欺诈被定罪的官员，将被禁止在任何M.I.公司担任董事，期限为10年。
