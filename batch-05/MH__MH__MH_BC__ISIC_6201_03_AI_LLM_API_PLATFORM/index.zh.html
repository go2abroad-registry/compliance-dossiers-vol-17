默认税务分类与身份选举

默认税务归类

免税区：从事零RMI业务的非居民国内企业可免交马绍尔群岛所得税；无需缴纳资本利得税，也无需向非居民支付股息、利息或特许权使用费，同时也不需缴纳增值税/ GST；任何来自RMI的收入，如果产生的话，将仅按地域原则征税。

支持身份选举表单

不存在国内那种选择式选举机制。根据1990年《商业公司法》，公司章程可以设定为“非居民国内公司”身份，这种公司作为自动执行的法定免税实体，可避免缴纳马绍尔群岛所得税，前提是该公司没有来自马绍尔群岛的收入，且未在马绍尔群岛境内设立任何永久机构、办公室或业务活动。混合型不匹配选举则不可行：马绍尔群岛共和国没有完整的双重税收协定网络（仅与美国之间存在有限的协议），而1989年《所得税法》（经修订）中也未规定关于混合实体或混合工具不匹配的相关条款。

流转税 (VAT / GST) 与出口 0% 零税率

标准增值税/流转税率

无（无增值税/GST/销售与使用税）。唯一的间接税是进口税（《2014年海关法》规定的关税和消费税），仅适用于进口至密克罗尼西亚联邦的有形商品，与无形的AI/LLM API服务无任何关联。

强制登记营业额门槛 (Nexus)

不适用——不存在增值税/GST制度；没有营业额门槛会触发增值税登记。仅对实际进口货物进入瑞马岛（RMI）的进口商需要办理进口税登记（无金额门槛；《2014年海关法》）。

跨境出口 0% 零税率申报条件

RMI不征收增值税/ GST，因此不存在或不需要出口零税率机制。由非居民国内公司向外国客户提供的AI/LLM API服务属于RMI税收范围之外的情形：当(a)没有来自RMI的收入；(b)服务完全在RMI之外提供和消耗；(c)没有在RMI设立固定机构、办公室或代理来签订合同；以及(d)收入通过外国支付渠道（如Stripe）以美元、USDC或其他加密货币形式在海外收取时。此类出口被假定为免税的，无需申请退税。

  • 数字交付日志：记录API使用遥测数据及令牌消耗账目，证明境外服务交付

在RMI中，没有电子发票、实时税务结算、API申报或数字印章相关的规定。海关申报是通过UNCTAD ASYCUDA World进行电子处理的，但这一机制仅适用于实体进出口货物。数字AI/LLM API令牌交易和跨境云支付则完全不属于任何间接税收结算机制的范围。

经常项目兑换自由度

美元是唯一的法定货币和功能货币。经常账户（API订阅费、特许权使用费、服务收入）和资本账户（股权注入、股东贷款、股息汇回）均可完全转换；对于位于免税区的非居民拥有的企业公司，无需办理外汇管制许可、事先审批，也无需缴纳利润汇出税。实际障碍仅来自交易银行的人头审核/美国外国资产控制委员会审查以及对应方风险降低措施，而非法定可兑换限制。

转让定价与经济实质

主文档/本地文档门槛: 在当地法律层面并不适用：RMI没有转移定价法规，也没有相关法规要求必须编制本地文件或主文件，对于非居民BC企业来说，也不存在按国家分列的报告要求。不过，外国母公司所在司法管辖区（尤其是美国）可以依据IRC第482条自行重新确定公司间AI/LLM服务费用的性质。为了合规，每当支付与关联方相关的API许可或托管费用时，就必须保留符合OECD标准的转移定价文件——包括公司间协议、功能分析以及相应的定价基准。

经济实质审查范围: RMI中不存在经济实质法规（ESR）。由于该地区不征收所得税，因此也没有相应的税收制度来保障ESR的有效性。不过，一些国际反滥用规定（如美国的CFC/GILTI/Subpart F、欧盟的ATAD、OECD的BEPS）可能会无视无实质成分的商品税，即使不会引发RMI的处罚措施。此类商品必须保留RMI授权的注册代理机构，不得声称自己拥有RMI所要求的实质成分，也不得在任何外国申报中声称属于RMI的税务居民。

致命合规红线与董事个人责任

面向美国的逃税及FATCA合规不力

法定制裁: RMI方面：故意逃避任何需缴纳的相关税收属于犯罪行为，可处以最高10,000美元的罚款和最高5年的监禁。美国方面：IRC第7201条规定的犯罪逃避行为，每次可处以最高250,000美元的罚款和最高5年的监禁；IRC第6663条则规定处以75%的民事欺诈罚款；准确性方面的罚款为20-40%；FATCA规定，对于不合规的付款方，每份表格可处以10,000美元的虚假证明罚款，并根据第1471/1472条规定自动征收30%的美国来源预扣税。

董事个人责任: 签署虚假证明或导致遗漏的董事及高级管理人员，应承担连带的民事赔偿责任；美国法院可依据禁令实施旅行禁令、冻结个人资产、处以个人罚款，甚至监禁实际控制人；外国董事的美国签证及入境记录可作为故意行为的积极证据用于起诉。
RMI国内税务及营业执照违规

法定制裁: 未经许可的本地经营行为，将从经营活动开始之日起被追溯征税，并按年利率10%计收法定利息；若被查处，可能被处以最高5000美元罚款和最高12个月的监禁；提交虚假纳税申报的，将面临全额征税，并处以逃税金额50%的罚款。

董事个人责任: 明知导致无照本地贸易的董事，须就未缴的总营业收入税承担个人责任；当公司（BC）被用作掩护或视为同一实体时，揭开公司面纱，董事将面临民事赔偿、法定禁止任职令以及禁止离境的措施，从而在拉利马岛（RMI）管辖范围内实质上构成旅行禁令。
空壳公司及经济实质不足（欧盟上市与去风险化风险）

法定制裁: 不会适用RMI ESR处罚，但域外后果却类似：外国法院可以无视该实体并对其实施实体层面的处罚（例如美国的25% CFC外国基地公司收入重新认定规定；欧盟的ATAD反滥用评估规定）；支付基础设施（如Stripe、代理银行以及受监管的加密货币交易所）会因风险降低而终止账户；RMI注册机构也可能因未支付费用而取消公司的注册资格，导致合同义务由董事个人承担。

董事个人责任: 被提名董事因外国调查命令和藐视法庭制裁而面临个人风险，包括旅行禁令；美国或欧盟法院可能会下令揭开面纱调查，使股东和董事对公司的义务承担个人责任；制裁措施则禁止国际旅行并冻结个人资产。
反洗钱/反恐融资犯罪及数字货币支付渠道滥用

法定制裁: 根据2013年RMI犯罪法，洗钱行为可处以最高20年的监禁以及最高2,000,000美元的罚款，或洗钱所得财产价值的两倍，以较高者为准；RMI金融情报机构可以冻结并没收相关资产；美国电汇欺诈行为则属于18 U.S.C.所规定的犯罪。1343) 适用于 Stripe或往来银行进行转账的情况，每起事件将处以高达25万美元的罚款和20年监禁。

董事个人责任: 刑事责任直接适用于决策者和故意参与者；处罚措施包括个人财产没收、强制返还、在审判前实施旅行禁令，以及通过现有双边司法协助渠道面临引渡风险；在RMI或美国境内被定罪，将永久禁止董事从事银行业务、居留以及获得专业执照。
