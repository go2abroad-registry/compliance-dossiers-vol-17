官方税号申请基础设施

主管税务局

马绍尔群岛共和国财政部收入与税收处（马朱罗，MH 96960）；目前没有统一的国民所得税电子门户。企业注册和年度申报工作由企业注册局通过持牌注册代理人来办理（实际门户/账户访问权限由该企业的Majuro注册代理人持有）。

电子政务申报门户

对于非居民商业公司来说，无需办理法定TIN/增值税编号。RMI不征收一般企业所得税，而商业特权税则仅适用于“在共和国开展业务的人”。那些仅向非居民客户销售无代码网页构建软件的非居民商业公司，无需进行任何注册手续，也无需提供TIN。如果该商业公司后来开设RMI办事处、雇佣RMI员工或在当地销售产品，就必须在规定的注册期内向税收与税务部门登记并获取商业特权税账户号；除此之外，无需进行其他国家税收登记。

税号代号与申请路径: Tax_Exempt_Zone — 对于非居民商业公司来说，无需办理法定TIN/增值税编号。RMI不征收一般企业所得税，而商业特权税则仅适用于“在共和国开展业务的人”。那些仅向非居民客户销售无代码网页构建软件的非居民商业公司，无需进行任何注册手续，也无需提供TIN。如果该商业公司后来开设RMI办事处、雇佣RMI员工或在当地销售产品，就必须在规定的注册期内向税收与税务部门登记并获取商业特权税账户号；除此之外，无需进行其他国家税收登记。

默认税务分类与身份选举

默认税务归类

Tax_Exempt_Zone

支持身份选举表单

RMI没有“选择式制度”，也没有混合差异选举机制，因为该地没有所得税法规。相关的法定选择就是根据《企业法》进行的企业状态选择：不列颠哥伦比亚省可以在其章程中指定自己为“非居民国内企业”（没有RMI办事处、资产或业务），这样就能被排除在BPT之外，并获得免税处理资格。通过向注册处提交必要的声明，也可以获得非居民身份。

流转税 (VAT / GST) 与出口 0% 零税率

标准增值税/流转税率

没有——RMI不征收增值税、GST或一般销售和使用税。间接税仅限于海关进口税、酒精/烟草/燃料的消费税，以及海洋产品2%的出口税。非BC省居民向外国客户提供的数字服务则不属于RMI的间接税范围。

强制登记营业额门槛 (Nexus)

不适用——不存在增值税/ GST阈值。在RMI开展业务活动后才需要办理BPT注册，非居民数字商家没有固定的低价值免税标准；没有与RMI有实体或销售关系的非居民BC则无需对任何本地货币金额进行注册。

跨境出口 0% 零税率申报条件

不适用——RMI没有增值税/ GST制度，因此也没有0%出口税率或退税机制。非BC省居民所出口的数字软件/SaaS产品完全不在RMI的征税范围之内；无需提供零税率证明、出口凭证或退税申请。

没有——无需进行电子发票开具、实时财务结算、API结算或数字印章操作。Stripe和Paddle支付系统及商家记录可以自愿保留，用于企业账目、银行KYC要求以及OECD CRS申报，但无需经过RMI财务审批。

由于不存在零评级退款机制，因此也没有相关的追回资金措施。一般执行措施方面：那些虚假申报为“非居民”但实际上在RMI开展业务的企业，可能会被追溯对RMI来源的总收入进行BPT征收，同时还会面临利息以及迟报/迟付的罚款；虚假税务或海关申报则依据RMI税收和海关法律面临民事欺诈处罚以及刑事罚款或没收处罚；RMI不实施外汇管制，因此180天的回国规定是遵循外国银行/支付渠道的要求，而非RMI的法定期限。

外汇管制与央行政策诊断

经常项目兑换自由度

RMI不实行任何外汇管制制度；经常账户和资本账户交易均可自由且完全兑换，因为当地货币为美元。对于向非居民股东汇发股息、利息、特许权使用费或服务费用并无法定限制，且利润回流也无需中央银行的批准。实际障碍主要限于商业银行的尽职调查、对应银行链制裁筛查以及远程投资或离岸持有行为的风险降低问题；货币交易报告则以10,000美元为阈值进行申报。

出口外汇强制结汇要求

在RMI中，出口收入并不受任何法定交付期限、强制转换比例或遣返要求的约束。非居民商业公司可以自由地保留、分配和支付SaaS订阅收入及其他出口收益，无需将其转换为授权经销商所要求的金额。唯一的义务包括记录保存、货币交易报告，以及根据《2012年洗钱控制法》向金融情报机构报告可疑交易，同时遵守与美元清算链相关的美国金融管理局或同行银行合规要求。

央行监管: 马绍尔群岛共和国没有国内的中央银行或外汇管理机构；根据1982年《货币法》，美元是唯一的法定货币，因此货币政策和货币状况实际上由美国联邦储备系统决定。银行及金融机构的许可审批、审慎监管以及反洗钱/反恐怖融资措施的执行工作则由马绍尔群岛财政部银行事务局负责，而马绍尔群岛金融情报机构则依据2012年《洗钱控制法》提供支持。

跨境清算通道与结算适配

资本注入必须以美元通过SWIFT MT103电汇，或当资金来源于美国时通过Fedwire/CHIPS，汇入马绍尔群岛银行或关岛银行的RMI账户受益人BIC或ABA路由号码。汇款须注明认购协议、贷款协议或股本协议，并附有国际公认的ISO 20022目的代码，例如EQUI用于股权出资，LOAN用于集团内部贷款，ROYA用于版税及软件许可费，CCFT用于成本与费用转移。RMI未规定法定目的代码表或外汇管制事前通知要求；但单笔或累计金额达到1万美元以上的美元汇款，须向金融情报单位进行交易申报，金额超过25万美元的汇款则需由收款银行进行加强的资金来源核实。为避免隐性股权被重新定性，所有资本注入必须以以下两种方式之一进行书面记录：一是通过认购协议及董事会会议纪要证明已实缴的股份；二是通过经公证的股东贷款协议，该协议应包含还款计划、利率条款以及集团内部转让定价文件，以证明其为独立、公允的股东贷款。对外资金支付通过以下方式完成：(i) 对于供应商款项、工资支付、托管服务及营销费用，使用SWIFT MT103方式进行支付，由RMI银行指示其美国代理行采用Fedwire或CHIPS方式进行结算；(ii) 对于代理链间的流动性转移及当日支付，使用SWIFT MT202/COV方式进行支付；(iii) 对于需要银行担保结算的基础设施采购、软件开发或设备采购项目，使用SWIFT MT700/MT707及ICCC UCP 600方式进行商业跟单信用证支付；(iv) 对于客户退款、扣款及订阅账单调整等交易，使用Stripe Billing和Paddle进行卡组织清算，将资金转入或转出美元账户。所有对外支付都需经过代理链对OFAC及其他制裁机制进行审核；无需中央银行批准，但银行仍需按法定标准提交相应的货币交易报告和可疑交易报告。目前没有内RMI外汇市场，因此对冲行为只能通过母公司财务部门、持牌美国经纪商或非居民银行来进行，并且必须得到RMI实体有记录的资产负债表或承诺的现金流风险支持。交付欧元/美元、英镑/美元和澳元/美元的远期外汇合约，用于已确认的发票和已承诺的付款。对于兑换受限或美元清算访问有限的货币，非交割远期（NDFs）以美元进行现金结算。以ISDA 2002主协议与掉期交易商签署的跨境货币利率互换及货币互换，且已执行信用支持附件。场外及上市外汇期权（包括看跌期权、看涨期权以及零成本对冲组合），用于对冲订阅收入波动及未来流动性事件的风险。与对应银行建立外汇掉期及T+1流动性额度，以应对因Paddle或Stripe结算周期产生的当日融资错配。

第6条 — 董事声明及免税地位 董事或代理人出具的证明，证明该公司未从马绍尔群岛境内获得收入，并持续符合免税离岸地位的资格。 非居民BC必须确认其没有来源于国内的收入，且在密克罗尼西亚联邦领土内没有实体经营场所；虚假申报将导致处罚。 延迟提交文件将面临100美元的行政罚款，此外还需支付每逾期一天5美元的罚款（法定上限为每份年度报告500美元）；长期不提交文件则会导致机构被解散、信誉丧失、良好状态证明被取消，且在重新进行公证或银行开户之前，必须支付恢复信誉费用。

转让定价与经济实质

主文档/本地文档门槛: 不适用——非居民BC没有企业所得税基础，因此无需执行公平交易调整机制、本地文件或主文件文档要求；实际阈值为零美元（无税收抵免规定）。

经济实质审查范围: 适用——《2020年经济实质规例》（依据《经济实质（实施）法》制定）要求国际公司，以及在特定情况下从事“相关活动”的商业公司，在马绍尔群岛境内必须证明具备充分的实质：包括在马朱罗召开董事会和进行管理、保持本地账簿和记录，以及配备足够员工并支出与业务活动相称的费用。针对该目标无代码网站构建平台（ISIC 6201），必须特别评估其是否属于“知识产权业务”类别：若该平台在马绍尔群岛境内获得版税或许可收入，则必须提交完整的ESR报告，并提交CIGAR（核心收入产生活动）申报表。若该商业公司仅持有运营附属公司的股权，仅获得股息和资本利得，则可享受“被动纯股权持有”豁免，无需满足活跃业务实质要求。未提交ESR年度报告的行为被视为一项独立的可登记违规行为。

致命合规红线与董事个人责任

逃税及无照国内经营

法定制裁: 按照适用的所得税法税率对国内企业所得税进行追溯评估，同时加上因少缴税款而产生的利息和罚款；营业执照罚款最高可达5,000美元；登记机构可以将公司从登记名单中除名，并撤销其良好经营证明证书。

董事个人责任: 董事及高级管理人员在明知情况下授权进行无许可的境内交易，可能需就已扣缴或已评估的税款承担个人责任；对于不当分配股息的行为，需承担民事赔偿责任；对于作出虚假声明的行为，可能面临罚款和监禁的刑事处罚。
经济实质不合规

法定制裁: 初始罚款最高为10,000美元；持续违约将产生额外罚款，最高可达20,000美元；注册机构可更换或解除注册代理人，公司可能被从注册名单中除名。

董事个人责任: 明知批准虚假环境社会责任（ESR）声明的董事，将面临个人罚款，并可能被禁止担任董事职务最长五年；高等法院可根据跨境实质套利调查的需要，实施旅行禁令和资产保护令。
反洗钱与空壳公司滥用（反洗钱）

法定制裁: 公司罚款最高可达50万美元；自然人将面临最高15年的监禁刑罚；可实施资产冻结和民事没收令；外国税务机关可启动国际司法协助程序。

董事个人责任: 董事及合规官对共谋以及明知而容许洗钱行为承担个人刑事责任；高等法院可在引渡或相互司法协助过程中发出旅行禁令和出境限制；一旦定罪，将面临强制监禁。
欺诈性经营及对债权人作出虚假陈述

法定制裁: 司法清算、有利于债权人的民事赔偿命令；《企业法》规定的对虚假法定声明行为的处罚，每次违规可处以5,000美元的罚款；董事不得管理任何RMI企业实体。

董事个人责任: 公司的面纱被打破：董事对欺诈性交易负有无限责任；高等法院可以发布逮捕令和旅行禁令，实施资产保护命令；一旦被定罪，董事可能面临最高5年的监禁。
