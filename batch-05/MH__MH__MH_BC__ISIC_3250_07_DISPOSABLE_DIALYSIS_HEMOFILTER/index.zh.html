官方税号申请基础设施

主管税务局

财政部—征税与税务办公室（RTO）；无统一的电子门户；通过纸质表格在马朱罗或埃比耶的RTO办公室提交注册。

电子政务申报门户

外国非居民实体通过以下方式获取税务识别号（TIN）：（i）向相关机构提交RTO表T-101《税务识别号申请表》，并附上其公司注册证书的经认证副本；（ii）提交关于非居民身份及无本地商业活动的具誓声明；（iii）如需进行法律程序服务，须指定马绍尔群岛的注册代理人；（iv）支付50美元的注册费以及任何年度非居民商业公司维持费；（v）获得TIN。由于马绍尔群岛不征收增值税，因此不会另行发放增值税识别号（VAT ID）。

税号代号与申请路径: Tax_Exempt_Zone — 外国非居民实体通过以下方式获取税务识别号（TIN）：（i）向相关机构提交RTO表T-101《税务识别号申请表》，并附上其公司注册证书的经认证副本；（ii）提交关于非居民身份及无本地商业活动的具誓声明；（iii）如需进行法律程序服务，须指定马绍尔群岛的注册代理人；（iv）支付50美元的注册费以及任何年度非居民商业公司维持费；（v）获得TIN。由于马绍尔群岛不征收增值税，因此不会另行发放增值税识别号（VAT ID）。

默认税务归类

Tax_Exempt_Zone

支持身份选举表单

不存在“勾选选项”式的选举方式。非居民商业公司可根据《商业公司法》选择仅在马绍尔群岛共和国外部开展业务，从而无需缴纳总收入税和净收入税。根据马绍尔群岛的税法，也不存在混合不匹配的选举选项。选择在当地开展业务的实体则须遵守《1989年所得税法》及总收入税制度。

流转税 (VAT / GST) 与出口 0% 零税率

标准增值税/流转税率

无（不征收增值税、销售税或使用税；仅对来源于RMI的业务收入征收3%的直接毛收入税）。

强制登记营业额门槛 (Nexus)

不适用——RMI不要求进行增值税/ GST/销售税登记。只有当非居民实体选择在马绍尔群岛开展本地贸易或业务时，才需要填写总收入税登记表（T-201表格），且没有规定最低收入门槛。

跨境出口 0% 零税率申报条件

由于RMI不征收增值税/GST，因此无法适用法定零税率机制。由非居民商业公司进行的出口销售，如果未涉及RMI贸易或业务，则不受RMI直接税的影响，因此可享受真正的零税收待遇。如果该实体在RMI境内开展业务，则出口交易无法获得任何明确的免税优惠；税收中性状况则取决于该企业是否属于非居民企业，或者其收入是否来自马绍尔群岛，具体取决于所得税法的规定。

  • 海关出口申报单（RMI海关单证CED-1）

外汇管制与央行政策诊断

经常项目兑换自由度

当前账户和资本账户交易均实现法律上和事实上可自由兑换。RMI是国际货币基金组织第八条成员国，对利润、股息、贷款偿还及贸易结算的汇回不存在外汇管制限制。对于位于免税区的非居民公司，利润汇回不受限制，且不征收股息预提税；然而，若产生来源于RMI的总收入，则可能适用3%的总收入税，但鉴于该企业为非本地来源收入的制造或贸易实体，且未产生本地来源收入，此项税收在实质上不具适用性。在实际操作中，是由美国的代理清算银行通过OFAC审查和受益所有权筛查来实施可兑换性操作测试，而非依据RMI的法律条文。

出口外汇强制结汇要求

没有。RMI不规定任何法定的转让期限、强制转换比例，也不要求对出口收入进行遣返处理。出售一次性透析血滤器所获得的硬货币收入，可以保留在美元中，用于直接支付外国供应商的发票款项，或者通过RMI许可的银行或外国代理银行进行清算，只要相关的交易符合美国OFAC的规定以及该银行的反洗钱/客户身份识别程序即可。

央行监管: 马绍尔群岛共和国财政部银行与保险局银行监管专员。马绍尔群岛共和国没有本国中央银行；其货币政策与美国联邦储备系统保持一致，因为根据自由联系协定，美元（USD）是唯一的法定货币，且《1991年银行法》规范所有获准经营的银行和信托公司。

跨境清算通道与结算适配

推荐路线：股东/母公司银行 → 美国货币中心代理行（如摩根大通或美国银行纽约分行） → 关岛银行（关岛美国结算点） → 关岛银行马朱罗分行的RMI运营账户。使用包含唯一端到端交易参考号的SWIFT MT103报文；描述字段应为：“股权资本投入——2024年股份协议——MH_BC聚醚砜透析设备工厂”。根据RMI法律，无需进行资本审批或用途代码审核，但接收银行会要求提供以下文件：(i) 授权投资的经认证董事会决议；(ii) 更新后的股份登记册和溢价账本；(iii) 汇款股东的资金来源证明；(iv) 若金额超过50万美元，还需由首席财务官或董事签字的资金确认文件。为了获得最佳清算服务，建议使用符合ISO 20022标准的字段，并发送camt.053/camt.054通知；整个美元交易通过Fedwire/CHIPS完成，无需进行外汇兑换。主要清算方式：通过关岛银行进行USD SWIFT MT103（GPI）交易，用于金额低于250,000美元的运营支出，包括灭菌服务、运输费用、法律费用以及检测实验室相关费用。对于价值较高的聚醚砜树脂、中空纤维膜卷、封装材料及注塑外壳等采购项目，则应使用由关岛银行开具的不可撤销商业信用证进行结算，该信用证采用MT700格式并遵循MT707条款；预付款则通过MT798银行间退款机制处理。对于以日元或欧元结算的日本或德国供应商，应获取以美元计价的信用证报价，这样RMI BC在清算过程中就不会持有未对冲的外汇资产；结算工作则在确认银行进行。对于cGMP洁净室设备的进口业务，则应使用备用信用证（URDG758），并附加MT760形式的保证条款。所有支付记录必须注明相应的采购订单、发票号码以及HS编码（9018.90 / 3920.69），以确保审计记录的完整性。美元即期——为默认且唯一的功能货币结算渠道；对于美元入/美元出业务无需进行对冲。直接交付的美元/欧元远期合约——仅允许与受美国监管的货币中心银行（如关岛银行/摩根大通）合作，期限不超过12个月，且必须与以欧元计价的供应商发票严格配套，该供应商提供的是聚醚砜树脂或德国洁净室组件的相关订单。直接交割的美元/日元远期合约——当日本空心纤维膜供应商以日元开具发票时允许使用；对冲比例上限为公司采购订单金额的100%，通过确认银行的外汇结算指令进行结算。交叉货币利率互换（CCIRS）——原则上仅在MH_BC后续通过美元/欧元银团贷款融资设备时才可允许；对于由股权融资的附属制造资金中心而言，目前并不需要，应避免使用以降低交易对手风险。外汇对冲/零溢价期权结构——若远期交割存在操作上的不确定性，经美国经纪商同意，可允许进行多币种成分采购；期权溢价和行权价须与原始采购订单一致，并须经董事会决议批准。非可交付远期合约（NDFs）——是不被允许的，且根本无法发挥作用，因为RMI没有本国货币，而美元是法定货币；任何NDF报价都只是USDBRL/USDJPY的虚拟叠加价格，没有任何合理的对冲或会计依据，从而带来与该实体财务管理目标不相符的投机风险。

转让定价与经济实质

主文档/本地文档门槛: 不适用——RMI所得税法中没有任何转让定价相关规定，也没有本地文件或主文件阈值的规定。RMI不需要遵循OECD标准下的转让定价文件要求。不过，当RMI实体参与全球供应链时，外国税务机关可能会重新评估其交易性质；谨慎的做法是保留相关的基准研究资料，以便该实体能够向相关方开具发票。

经济实质审查范围: 《2019年RMI经济实体法规》及其后续修订版适用于从事“相关活动”的非居民国内企业，这些活动包括分销和服务中心、融资与租赁业务、控股公司业务以及知识产权持有业务。制造和制造空心纤维透析器并不属于明确列出的相关活动，但如果该企业在RMI境内自行或通过第三方进行本地分销，或者从知识产权中获取收入，而核心职能则依赖外国子公司完成，那么就必须提交年度经济实体报告，且该企业必须证明其在RMI内的核心收入来源、合格员工、办公场所以及与收入相称的运营支出情况。

致命合规红线与董事个人责任

逃税 / 滥用离岸吸收

法定制裁: 在RMI不征收所得税，因此海外辖区会立即实施相关处罚：禁止公司间扣除费用、重新分配利润、处以20-40%的罚款（美国）或高达100%的罚款（其他地区），以及对控制外国公司的归属问题进行处理。在RMI境内，年度报告中出现虚假陈述的行为将面临最高10,000美元的罚款和最高五年监禁的惩罚。

董事个人责任: 授权虚假合同的董事将面临境内司法管辖区的民事返还责任，并因董事罚则条款承担外国公司税的个人责任；拉美岛注册署可因虚假认证而撤销公司登记，从而揭开公司面纱。
空壳公司 / 经济实质缺失

法定制裁: 首次违约的ESR财务罚款为每项相关活动5,000美元至20,000美元；后续违约的罚款为每项相关活动20,000美元至100,000美元；注册官可向法院申请撤销、解散及公开谴责，从而终止该实体的法律存在。

董事个人责任: 董事在批准虚假实质声明的情况下，需对ESR罚款承担连带及个人责任；根据国际税务合规框架，他们可能面临RMI税务信息机构的旅行禁令和信息交换请求。
反洗钱 / 隐匿受益所有权

法定制裁: 根据2018年RMI反洗钱法，虚假或遗漏的BOI申报行为将面临最高10万美元的罚款和最高十年监禁；该实体的注册可能被暂停，注册代理人必须退场，从而导致企业结构崩溃。

董事个人责任: 董事及常驻代理人对明知虚假的受益所有人（BOI）申报承担刑事责任；洗钱金额的民事追偿可针对其个人资产执行，且在调查期间通常会实施旅行禁令。
无许可证的本地商业活动

法定制裁: 无许可证经营将面临每日最高500美元的罚款，同时对所有源自RMI的收入征收3%的GRT倒扣税，对进口商品征收海关罚金，并没收库存。

董事个人责任: 董事及高级管理人员对该公司因直接财务利益而产生的未缴许可证费、GRT欠款及罚款承担个人责任；法院可依法裁定禁令并没收其个人财产。
欺诈性股利分配 / 逃废债务行为

法定制裁: 根据《公司法》中关于非法分配的规定，董事必须退还全部非法分配款项及利息；股东的故意欺诈行为构成刑事犯罪。

董事个人责任: 董事对超出部分需对公司及其债权人承担连带责任；公司法人地位被穿透，可追究个人破产、民事赔偿及欺诈罪的监禁责任。
滥用非居民豁免条款 / 误导性陈述

法定制裁: 撤销非居民免税待遇，对所有本地收入追溯征收3%的毛收入税，每月加收1.5%的滞纳金及利息，并对故意逃税行为移送司法机关追究刑事责任。

董事个人责任: 相关董事及高级管理人员需个人承担补缴税款及罚款；RMI税务与海关办公室可实施旅行禁令并采取冻结资产措施以保障税款的追缴。
