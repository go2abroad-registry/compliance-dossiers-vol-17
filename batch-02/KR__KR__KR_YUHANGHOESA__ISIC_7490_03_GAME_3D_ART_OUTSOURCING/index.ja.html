Master / Local File threshold: 韓国国内企業の海外関係者取引額が年度に500億ウォンを超える場合は、ローカルファイルを準備・保持する必要があります。多国籍グループの連結収入が少なくとも1000億ウォン以上の場合は、マスターファイルが必要です。また、グループの連結収入が1兆ウォンを超える場合は、国別報告書が必要となり、その際には国際税務調整法およびその施行令に定められた基準や免除が適用されます。
