外汇管制自由度 韩国实行一种以自由化为主但具有正式监管的外汇制度。通过持牌外汇银行进行经常账户交易时，包括与贸易相关的支付、服务费用以及普通汇款等，通常无需事先批准即可自由兑换；银行会根据法定用途代码记录这些交易，并开展反洗钱审查。资本账户交易，包括国内资本注入和海外投资，同样被允许，但需向经济财政部或韩国银行提交强制报告；而外国直接投资则必须根据《外国投资促进法》进行申报，才能获得资本验证和回流保护。利润和股息在提交经审计的财务报表、税务支付证明、董事会决议以及外汇银行相关文件后，可以汇出境外，但银行必须核实企业的盈利能力以及是否存在未解决的税务或海关问题。退保要求有限：出口收入必须通过持牌银行收取，可以保留在外币账户中，或按市场汇率转换为韩元；没有强制退保比例规定。实际操作中存在一些障碍：对海外股东需要严格的KYC/BO身份确认，必须提供资金来源的书面证明，且在开设托管或运营账户之前，还需取得外国直接投资报告证书。

外汇管制与央行政策诊断

经常项目兑换自由度

韩国实行一种以自由化为主但具有正式监管的外汇制度。通过持牌外汇银行进行经常账户交易时，包括与贸易相关的支付、服务费用以及普通汇款等，通常无需事先批准即可自由兑换；银行会根据法定用途代码记录这些交易，并开展反洗钱审查。资本账户交易，包括国内资本注入和海外投资，同样被允许，但需向经济财政部或韩国银行提交强制报告；而外国直接投资则必须根据《外国投资促进法》进行申报，才能获得资本验证和回流保护。利润和股息在提交经审计的财务报表、税务支付证明、董事会决议以及外汇银行相关文件后，可以汇出境外，但银行必须核实企业的盈利能力以及是否存在未解决的税务或海关问题。退保要求有限：出口收入必须通过持牌银行收取，可以保留在外币账户中，或按市场汇率转换为韩元；没有强制退保比例规定。实际操作中存在一些障碍：对海外股东需要严格的KYC/BO身份确认，必须提供资金来源的书面证明，且在开设托管或运营账户之前，还需取得外国直接投资报告证书。

出口外汇强制结汇要求

根据《外汇交易法》，出口收入必须在出口审批日期起4个月内收取，除非外汇银行同意延长期限；收款后没有强制的留存比例要求，全部收入可以作为外币存款持有，或兑换成韩元。所选处理方式需按照出口收汇结算代码报送给相关银行。

央行监管: 韩国银行（BOK）依据《外汇交易法》和《外国投资促进法》，通过授权的外汇银行及韩国海关服务，行使外汇管理与执法职能，以及对交易者的申报管理。

转让定价与经济实质

主文档/本地文档门槛: 一个财年中，跨境关联方交易总额达到100亿韩元，这要求必须在企业税务申报截止日期后45天内准备并提交本地文件及主文件给NTS；如果金额低于该阈值，仍需同时准备相关交易文件，因为NTS可能会要求这么做，且若未在60天内提供记录，还将面临处罚。

经济实质审查范围: 尽管韩国并未设立类似海湾国家的独立经济实质规制制度，但其税法通过《国家税收基本法》第14条、《韩国国际税收协调法》以及OECD税基侵蚀与利润转移行动6项关于条约滥用保护条款，适用实质重于形式的原则。韩国的反向物流企业必须证明其在韩国境内存在真实的、产生核心收入的经营活动，包括实体仓库设施、本地管理人员、运营风险、库存控制决策、分级团队以及与客户的直接接触；若企业仅为空壳实体，无员工且无实际商业决策，则可能被重新定性，导致丧失税收协定优惠、预提税重新评估、转让定价调整，甚至面临刑事税务欺诈风险。

致命合规红线与董事个人责任

税务犯罪 / 伪造申报

法定制裁: 《逃税者处罚法》第3条：可处以不超过5年的监禁或不超过逃税金额3倍的罚款；此外，还须缴纳相当于少报税款40%的罚款，并支付每日0.022%的利息；若逃税金额超过50亿韩元，则处以5至10年的加重监禁，且所享受的税收优惠将被没收。

董事个人责任: 当董事总经理与外国实际所有人共同策划欺诈计划时，公司面纱就被打破；董事们需对其个人资产所涉及的公司税、附加费及刑事罚款承担共同责任；NTS可以实施旅行禁令/列入黑名单措施，没收银行账户和房产，而相关董事及实际所有人则可能在韩国面临监禁，并可能需要通过国际刑警组织的红色通报进行协作处理。
空壳公司 / 条约滥用 / 缺乏经济实质

法定制裁: 根据《国家税收框架法》第14条、《韩国国际税收调整法》以及OECD BEPS行动6，基于“实质重于形式”原则，韩国税务当局可以重新评估被视为虚假交易的情况，计入公平交易收入，拒绝给予股息和特许权使用费方面的条约优惠，并处以40%的不合理收益罚款加上每天0.022%的利息；如果确认存在虚假交易行为，则依据《逃税者处罚法》进行起诉。

董事个人责任: 故意利用韩国公司作为空壳的董事及股东，须就重新核定的全部税款及罚款承担个人民事责任；韩国法院在公司资本不足且缺乏独立法人身份的情况下，可揭开公司面纱；外国股东可能被个人列入黑名单，其在韩国的资产可能被冻结，且可能被启动引渡或红色通缉程序，当地代表人将被判处监禁，情节严重者，外国股东亦可能被作为共同责任人予以监禁。
反洗钱/受益所有权申报/未披露的国际基金流动

法定制裁: 反洗钱报告及金融交易信息使用法第33条：违反反洗钱报告规定的，处五年以下有期徒刑或罚款不超过5000万韩元；外汇交易法规定，未申报的资本交易将处五年以下有期徒刑或罚款不超过1亿韩元；合并的国税和海关审查可能额外征收未申报收入税20%及虚假申报处罚40%。

董事个人责任: 董事、合规官及最终受益所有人将因主要违法行为而面临刑事起诉；韩国金融情报单位和韩国海关不会因公司法人地位而免除个人财产没收、银行账户冻结、旅行禁令或列入黑名单的处罚；管理层可能面临监禁，每位相关董事均需对所有未缴税款、罚款以及任何资产追踪调查所产生的费用承担连带责任。
