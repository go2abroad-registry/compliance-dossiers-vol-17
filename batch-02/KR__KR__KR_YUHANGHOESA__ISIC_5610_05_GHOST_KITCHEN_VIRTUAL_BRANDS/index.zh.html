商业开户与外汇资金池

央行经常项目外汇管制诊断、本土商业大行与离岸数字EMI矩阵、拒单痛点防御指南。

外汇管制自由度 韩国实行由《外汇交易法》规定的双账户制度。韩元可以在经常账户中完全兑换使用，包括与贸易相关的支付、出口服务的开票以及来自Yuhan Hoesa的利润汇出，只要相关交易有记录，并通过指定的外汇银行进行报告即可。不过，资本账户交易则需要事先报告或获得批准才能进行。非居民股东向韩国有限责任公司注入股权时，必须通过国内银行或韩国交易所信息系统提交资本交易报告。一旦股权被登记下来，股息汇出则被视为经常账户中的不可见款项，可以通过标准的税收预扣凭证汇出到国外。对于出口收入来说，没有一般的退保要求；韩国企业可以在国内银行的外币账户中无限期地持有外币，但出口收入必须在出口日期后的六个月内领取，除非得到延长。利润汇出的实际障碍包括：需要证明没有未缴税款，如果投入的资本超过法定标准，则必须提交经审计的财务报表，同时银行还会进行“实质重于形式”的审查，以确认分配行为不违反资本保存规则。韩国银行定期监测外币净头寸情况，银行也执行交易层面的检查，以防止洗钱行为。总体而言，韩元在真实的贸易和服务交易中可以轻易兑换，但所有交易都必须附带目的代码和相关合同，以满足报告要求。

法定注册代理人与物理地址 强制持牌代理

虚拟办公室或商业信箱被明确拒绝用于运营仅提供配送的“影子厨房”业务。根据《食品卫生法》，食品服务企业必须提交营业报告或许可证，以明确标识烹饪、储存及配送准备场所的具体物理位置。颁发许可证的市政政府以及当地区税务局均要求注册地址必须对应一个实际可租赁的商用厨房。韩国银行在开设企业账户时也拒绝接受虚拟办公室作为注册地址，因为反洗钱客户尽职调查程序要求提供物理场所的文件证明，通常还需进行现场访问。使用虚拟办公室将导致食品服务许可证被作废，阻碍税务登记，并危及UberEats、DoorDash等平台的付款渠道。

法定实缴资本与验资锁资账户流程 强制验资锁定

根据韩国商业法，不存在法定的最低实收资本要求。不过，所有认缴资本必须在提交注册申请之前完成缴纳，而创始人必须取得银行资本存款证明或认证储蓄存折，以证明这些资本已存入公司名义下的指定企业银行账户。无需设立单独的托管账户，但释放的资金仅限于公司设立费用，且必须在注册正式完成前保持未提取状态。实物出资必须经过评估，并载明在公司章程中。

注资与解冻路径: 该设施必须按照《消防安全安装与维护法》获得消防安全许可，包括对灭火器、喷水装置、紧急出口、自动火灾检测系统以及防火隔间进行检查。安装完成后，需由韩国消防安全局或当地消防站进行验收检查。为了进行应急规划，还需要进行民防登记，包括疏散路线、避难场所指定以及业务连续性计划等。在职业许可方面，必须遵守《职业安全与健康法》，在适用情况下需任命工作场所安全与健康管理者，并对热油烹饪风险、电气安全、通风系统维护以及配送服务人员的安全规范进行风险评估，所有这些内容都必须记录在案并随时可供政府检查使用。

实缴资本规则: 根据韩国商业法，不存在法定的最低实收资本要求。不过，所有认缴资本必须在提交注册申请之前完成缴纳，而创始人必须取得银行资本存款证明或认证储蓄存折，以证明这些资本已存入公司名义下的指定企业银行账户。无需设立单独的托管账户，但释放的资金仅限于公司设立费用，且必须在注册正式完成前保持未提取状态。实物出资必须经过评估，并载明在公司章程中。

董事会首期决议范本 (Pro-Forma First Board Resolution)
根据韩国商业法第555条及公司章程第3条，由YuHang HoEsa（有限责任公司）的首届董事会决议通过，以一致书面同意方式实施。  

鉴于该公司依据韩国商业法成立为Yuhan Hoesa（有限责任公司），旨在运营多品牌云厨房服务设施；  
鉴于有必要根据韩国商业法及其相关法规建立资本结构、银行授权、注册办公室、法定人员及企业治理机制；  
鉴于董事及唯一股东认为，注册程序所需的初步行动应经本决议批准。  

因此，决定如下：  

1. 资本认购与出资。每位初始认购人须按资本认购表规定全额缴纳出资款。首席执行官负责接收已缴资本，以公司名义开设专用企业银行账户，获取银行资本存款证明，并将账户中的资金保留至公司注册完成为止。除董事会批准的预注册注册费用外，不得提取任何认购资本。  

2. 银行授权。董事会及其授权人员有权执行所有必要的银行相关决议、签名卡、电子转账指令及电汇指示，以开设、维护并运营公司主要运营银行账户。这些人员可将该账户与UberEats和DoorDash等数字支付与配送平台连接，并与这些平台签订相关协议、安排及结算文件。主席、首席执行官及首席财务官，或其中两人共同担任授权签署人。  

3. 注册办公室。公司的注册办公室应位于公司章程中规定的地址，首席执行官有权签订租赁协议，向国家税务服务局商业登记处及企业登记处提交注册申请，并获取房东提供的必要租赁许可。  

4. 法定人员的任命。董事会选举并任命首席执行官、首席财务官及合规与食品安全官员。每位官员有权准备、公证、签署、盖章并提交所有设立文件、官方登记表、税务申报及监管许可申请，并可在政府机构面前出庭。

跨境出口 0% 零税率申报条件

零关税适用于通过向韩国海关提交出口申报而出口至韩国的商品，以及根据韩国增值税法被认定为在韩国境外提供的服务，包括提供给非居民接收方的符合条件的国际服务和数字服务。纳税人必须证明这些商品已实际出口，或服务已实际提供给外国交易方，且以外币支付的对价已从外国买家处收到，同时相关的法定出口文件也已被保存。对于“幽灵厨房”和虚拟品牌商业模式，通过平台支付进行本地韩国配送的销售额按10%的标准计算；只有针对包装食品的实体出口，或将虚拟品牌知识产权或数字内容授权给外国非居民买家时，才适用零费率。只要这些物资符合韩国的增值税供应地及出口证明要求。

  • 韩国海关通过UNI-PASS系统出具的出口申报单和出口清关证书
  • 海运提单或空运运单，证明货物从韩国的实际出口
  • 商业发票及装箱单与出口申报单相符
  • 由经许可的韩国外汇银行签发的外汇结算证书或汇款入账证明（FIRC），用以证明已收到出口收入
  • 如果通过代理人办理出口清关，需提供海关报关行授权或委托书

韩国没有采用实时财政预审批盖章模式。所有企业间交易物资必须通过强制性的电子税务发票系统进行记录，且发票必须以XML格式通过HomeTax或经认证的VAN服务提供商，利用NTS集成接口提交给NTS。普通季度申报中，电子税务发票最迟应在提供物资后的当月最后一天开具，并且必须在规定申报期限内提交给NTS。虽然没有针对每笔交易的反欺诈数字印章，但NTS会利用电子税务发票数据、企业间消费类货物的现金收入报告、海关出口申报文件以及外汇结算记录来进行自动交叉验证和审计监测。

国家税务局和韩国海关局共同对出口申报文件、电子税务发票、提单以及外汇结算记录进行比对。如果发现零税率出口缺乏依据、属于欺诈行为或无效，因为货物从未离开韩国、服务未提供给外国接收方，或者出口收入未在规定的180天内通过经批准的延期手续返回国内，那么国家税务局将取消零税率认定，并对全部供应商品按10%的增值税率征税，同时收取欠缴税款的利息。根据韩国增值税法，还适用其他税收处罚措施，包括因疏忽未申报或少报而面临最高20%的罚款，因欺诈逃避责任则面临最高40%的罚款。故意使用虚假出口申报文件、伪造运输单据或虚构外国接收方的行为，将根据《逃税者处罚法》构成犯罪行为，可能面临监禁和罚款，此外之前发放的增值税退款也将被追溯收回。一般的税收评估时效为5年，对于欺诈或故意隐瞒行为则延长至10年。

外汇管制与央行政策诊断

经常项目兑换自由度

韩国实行由《外汇交易法》规定的双账户制度。韩元可以在经常账户中完全兑换使用，包括与贸易相关的支付、出口服务的开票以及来自Yuhan Hoesa的利润汇出，只要相关交易有记录，并通过指定的外汇银行进行报告即可。不过，资本账户交易则需要事先报告或获得批准才能进行。非居民股东向韩国有限责任公司注入股权时，必须通过国内银行或韩国交易所信息系统提交资本交易报告。一旦股权被登记下来，股息汇出则被视为经常账户中的不可见款项，可以通过标准的税收预扣凭证汇出到国外。对于出口收入来说，没有一般的退保要求；韩国企业可以在国内银行的外币账户中无限期地持有外币，但出口收入必须在出口日期后的六个月内领取，除非得到延长。利润汇出的实际障碍包括：需要证明没有未缴税款，如果投入的资本超过法定标准，则必须提交经审计的财务报表，同时银行还会进行“实质重于形式”的审查，以确认分配行为不违反资本保存规则。韩国银行定期监测外币净头寸情况，银行也执行交易层面的检查，以防止洗钱行为。总体而言，韩元在真实的贸易和服务交易中可以轻易兑换，但所有交易都必须附带目的代码和相关合同，以满足报告要求。

出口外汇强制结汇要求

根据《外汇交易法》第32条及相关执行令，韩国出口商必须在出口日期（韩国海关清关或服务完成日期，以适用者为准）起6个月内收取出口收入。在银行批准的情况下，扩展期限可长达12个月；若提供BOK报告，则最长可达24个月。无需强制兑换为韩元；所得款项可以存入注册银行的外币账户，但全部金额必须汇回本国，不得留在海外。接收银行必须收到相关的发票和提单（或云厨房供应合同的交付确认书），以便生成外汇收支报告。若未能在规定时间内将资金汇回本国，将会面临行政处罚，甚至可能面临刑事制裁。

非居民股东的初始出资必须通过SWIFT MT103方式进行转账，并在韩国外汇信息系统中使用明确用途代码“A100 - 股权投资（非金融）”进行申报。接收方国内银行将根据股东名册核对汇款人姓名，出具外汇交易证明，并通过外汇信息系统将该交易报告给韩国银行。在汇款后的30天内，韩国实体必须向经济财政部提交资本投资报告，或通过接收银行进行自动报告。资本验证流程要求外部审计师或注册会计师对SWIFT收单、银行的信贷建议以及批准股票发行的董事会决议进行核对。对于没有最低资本要求的Yuhan Hoesa公司来说，一旦银行确认用途代码且“外国投资”自由转换流程获得批准，注入的资金就可以立即用于厨房设备采购、设备购买以及工资支付。如果股东使用非韩语中介机构，银行将实施加强式尽职调查，并要求提供完整的保管记录，以确保不存在第三方结算风险。对于原材料进口、包装供应及特许经营技术使用费的结算，韩国有限合伙企业应使用SWIFT MT103报文进行直接汇款，目的代码为“B210 - 进口付款”或“B310 - 版权费及许可费”。对于高价值或频繁发生的贸易往来，建议采用韩国一级银行开具的单据托收（DP/DA）或不可撤销保兑信用证，尤其在从日本或美国进口专用厨房设备时更为适用。本地供应商款项（如租金、公用事业费、第三方配送车队费用）通过国内银行支付网络（BOK-Wire+及CD/ATM切换系统）进行结算，采用标准的KFTC账户转账并附带结算信息。DoorDash和UberEats的付款通过平台的韩国收单机构以韩元形式到账，通常通过每日电子结算信息直接汇入运营账户；银行将据此与配送聚合商结算报告进行核对。对于跨境使用费的汇出，银行将要求提供相应的商标/专利注册证书、加盖谈判日期印章的许可协议以及韩国国家税务局出具的预扣税清关证明。所有单笔超过1万美元的汇款均需强制进行外汇申报，并实时核对联合国制裁名单及金融行动特别工作组（FATF）的监控名单。与经许可的韩国外汇银行签订的远期外汇合约，期限最长为12个月，涵盖根据预计原料进口发票及聚合商净结算所声明的美元/韩元或欧元/韩元敞口；必须进行实物交割，未使用的远期合约部分须在到期时平仓。根据韩国法规，非可交付远期合约仅限于非居民金融交易方参与；国内有限责任公司通常无法参与此类合约，除非能够向韩国银行证明自己拥有真正且符合要求的外币资产或负债，而该资产或负债无法进行实物交割。在股东向有限责任公司提供美元贷款并将其本金/利息兑换为韩元的情况下，允许进行跨境货币互换，但该互换必须通过国内外汇银行完成，并作为资本交易进行申报；禁止用于仅进行现金管理投机的非常规期权产品。对于UberEats Global和DoorDash US以美元计价的未来支付款项中出现的突然韩元升值情况，允许使用零溢价套保的普通外汇期权进行对冲。但银行要求提供由有限责任公司董事会批准的书面财务政策文件，以及证明这些套保措施能够降低而非增加公司外汇风险价值的分析报告。

电商与网关结算适配度: 低——对于韩国境内的业务来说，这种方式在法律上不可行。海外数字电子货币机构（如英国FCA认可的电子货币机构、欧盟电子货币机构许可证或美国金融科技BaaS平台）无权开设虚拟IBAN，也不得为韩国注册的公司提供韩元清算服务。《外汇交易法》要求所有本地货币结算和外汇兑换都必须通过在韩国获得许可的外汇银行进行。海外电子货币机构无法报告资本交易信息，也无法发放针对韩元的代码，也无法与韩国银行的报告系统对接。它们只能作为非韩国销售业务的辅助外币收款工具，但即便如此，也需要与国内银行进行跨境支付安排，这反而违背了初衷。因此，Yuhan Hoesa必须与一级国内商业银行建立主要合作关系。对于UberEats或门到门服务商的支付行为，根本不存在任何合法的解决途径；这些支付必须通过国内收购和结算渠道以韩元形式接收。

第5栏 应税收入计算：以第2栏的总收入为起点，减去第3栏的免税收入和第4栏的可扣除费用，然后应用结转的亏损（10年法定期间）及特殊法定扣除项，最终得出应税收入，再按税率进行征税。 来源于境外的收入，应就其全球收入对韩国居民企业征税。如果该韩国企业实际上为外国公司的分支机构或常设机构（PE）（此情况将在第1栏中确认），则仅包含来源于韩国境内的收入。亏损结转须满足业务连续性测试，并须以经审计的财务报表为依据。纳税申报表必须通过调整表对根据会计准则（GAAP）编制的财务报表中的应税收入进行核对。 逾期申报处罚：对于单纯未申报的情况，需缴纳未缴税款的20%；如果未申报是由于遗漏或收入申报不足造成的，则需缴纳40%（《国家税收框架法》第47-2条）。逾期付款附加费：每延迟一天，需按未缴税款金额的0.022%计算罚款（第47-3条）。未能提交必要的转让定价文件，根据《国际税收调整法》第11条，可能面临高达交易调整金额20-30%的处罚。故意逃税行为可处以最高2年的监禁或不超过逃税金额五倍的罚款（《逃税者处罚法》）；若逃税金额超过5亿韩元，可能面临最高5年的监禁。虚假扣税行为则需按月支付未扣税款的1%作为罚款。此外，相关当局还可以对负责人员实施旅行禁令（列入黑名单），并冻结其银行账户。
第6栏 税收责任与抵免：适用累进企业税率——对不超过2亿韩元的应税收入适用10%的税率；在2亿韩元至200亿韩元之间的收入适用20%的税率；在200亿韩元至3000亿韩元之间的收入适用22%的税率；超过3000亿韩元的收入则适用25%的税率。此外还需额外缴纳10%的地方收入附加税。对于研发、投资、已支付的外国税、就业等相关事项，以及其他法定抵免项目，可享受相应的税收抵免优惠。 就韩国实体就其全球收入所支付的税款，申请外国税收抵免，但抵免金额仅限于归属于境外收入的韩国税款。本年度已预缴的税款（临时税）计入本栏，最终应缴或应退税额将据此计算。如果韩国实体拥有非居民股东，其任何股息分配所涉及的预扣税在此处不予扣除——该项预扣税属于独立的预扣义务，将在股息分配时另行处理。外国母公司可享受的任何税收协定优惠，应在预扣税层面申报，而非在本企业所得税申报表中申报。 逾期申报处罚：对于单纯未申报的情况，需缴纳未缴税款的20%；如果未申报是由于遗漏或收入申报不足造成的，则需缴纳40%（《国家税收框架法》第47-2条）。逾期付款附加费：每延迟一天，需按未缴税款金额的0.022%计算罚款（第47-3条）。未能提交必要的转让定价文件，根据《国际税收调整法》第11条，可能面临高达交易调整金额20-30%的处罚。故意逃税行为可处以最高2年的监禁或不超过逃税金额五倍的罚款（《逃税者处罚法》）；若逃税金额超过5亿韩元，可能面临最高5年的监禁。虚假扣税行为则需按月支付未扣税款的1%作为罚款。此外，相关当局还可以对负责人员实施旅行禁令（列入黑名单），并冻结其银行账户。
