Master / Local File threshold: 韓国の事業者は、年間総売上高が1,000億ウォンを超え、国際的な関連当事者間取引の合計額が500億ウォンを超える場合には、移転価格に関するローカルファイルおよびマスターファイルを作成し提出する必要があります。また、越境関連当事者間の管理取引が50億ウォンの基準を下回る場合には、簡易的な移転価格開示表も必要です。さらに、必須文書の基準を下回っていても、Yuhan Hoesaは、越境企業間のロイヤルティ、サービス料金、クラウドインフラ料金、ソフトウェア配布に関する取引について、公正な価格に関する証拠を常時保持しなければなりません。

Economic substance scope: 韓国はカリブ諸国のような「経済実体規制」を適用していませんが、国家税に関する枠組み法および国際税務の調整に関する法律に基づき、「実体重視」の原則を適用しています。Yuhan Hoesaは実際に韓国でコア収益創出活動（CIGA）を行わなければなりません。つまり、実際の事務所、実際の従業員、タイ人の取締役会や経営決定、ノーコードウェブサイトテンプレートの知的財産に対する所有権と管理権、活発な顧客契約、そして日常的な製品開発が必要です。CIGAを行っていない韓国登録企業はシェル会社と見なされ、その韓国国内の税務居住者としての地位が問題となり、条約による利益、永続的営業所の保護、源泉徴収の削減などが認められない可能性があります。

Fatal Compliance Red Lines & Director Liability

収益を抑圧し、海外の支払いルートを活用して行われる税務规避

Statutory sanction: 「脱税者処罰法」第3条によれば、不正な申告や韓国の法人所得税の不正回避行為は、最大3年の懲役および脱税額の5倍までの罰金が科される。国家税務局は、国家税に関する枠組み法の第47-3条から第47-5条に基づき、未登録の場合20％、不正な過小申告による場合40％の過失税を課すほか、全額支払いまで毎日遅延料金を加算し、企業を常習的な高リスク納税者としてブラックリストに登録することもある。

Director personal liability: 虚偽の申告に署名した代表取締役や、オフショアルルートの利用を指示した実質的な取締役は、国家税収法第39条に基づき、未払いの法人税と、その取締役の個人資産に相当する罰金に対して個人的に責任を負う。刑事訴追により、投獄、渡航禁止、個人所有不動産や銀行口座、株式の没収、および取締役職の剥奪が行われる可能性があります。民事上の資産返還義務は、外国の子会社を通じて浪費された企業財産にも及びます。
人工的な取引価格および不適切な内部取引書類

Statutory sanction: 国家税務局は、国際税務調整法第4条および第5条に基づき、企業間の対価を適正な水準に調整することができる。また、過度な企業間手数料を禁止したり、不足分の法人税に対して不正報告の過失税を課したり、要求された際に同期の書類を提供しなかった場合には移転価格規制の罰金を科したり、遅延支払いに対する加算料を加えたりすることもできる。さらに、書類が偽造されている場合には、その取引を税務詐欺とみなすこともある。

Director personal liability: 偽の内部取引契約を承認した取締役は、国税収入法第39条に基づき、追加税額について連帯責任を負う。意図的な取引価格設定においては、取締役は虚偽の利益移転により税額回避を目的とした犯罪に問われ、旅行制限、財産の押収命令、および刑罰のリスクが生じる。会社の法的隠れを貫き、隠された利益および未支払のペナルティを回収する。
条約購入、シェル受益者、および不正な配当金・特許料のWHT減額

Statutory sanction: 国家税務局は、実質所有規定および所得税法第98-6条および国際税務調整法第9条に基づく韓国の条約違反防止規定に従い、条約による恩恵を拒否し、未払いの22％の源泉徴収税と地域附加税を評価し、20％/40％の未登録申告罰金を科し、遅延支払いに対する附加料金を請求する。DTAの請求が提出されていたにもかかわらず、支払い企業が法定額を徴収できなかったことについては、共同して責任を負う。

Director personal liability: 税住民票を提示せずに、または受益者所有を確認せずに虚偽の条約控除申告を執行した取締役は、国税収入法第39条に基づき、未収集の控除税について個人的に責任を負う。条約の回避が意図的かつ重大な場合、刑事責任が適用され、取締役は刑罰、出国禁止、個人資産の没収、および永続的なブラックリスト化にさらされる。一方、外国のシャルは、公表情報の公開からも危険を被り、不適格化のリスクにさらされる。
