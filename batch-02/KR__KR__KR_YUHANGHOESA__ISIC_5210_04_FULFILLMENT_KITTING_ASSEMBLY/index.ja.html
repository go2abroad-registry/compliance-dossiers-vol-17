Master / Local File threshold: 年間の国境を越えた関連会社取引が韓国ウォン50億円を超える場合、簡易国際取引報告書を年次会社税申告書と共に提出するものとする。年間の国境を越えた関連会社取引が韓国ウォン100億円を超える場合、完全な当地ファイルおよびマスターファイルの取引価格に関する文書を準備し、提出するものとする。最終母会社または多国間グループの統合収益が韓国ウォン1兆円を超える場合、国別報告が適用される。すべての文書は会社税申告期限後45日以内に提出しなければならない。文書の提出が行われない場合、取引価格が公正価格（正当価格）であることを証明する責任は納税者に移る。
