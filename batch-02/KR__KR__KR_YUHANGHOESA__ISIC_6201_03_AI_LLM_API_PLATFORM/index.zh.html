法定实缴资本与验资锁资账户流程 强制验资锁定

根据韩国商业法，无需采取任何措施；不过，公司章程中规定的全部已发行股本必须在提交注册申请之前存入韩国的冻结银行托管账户，且必须随同申请文件一起提供银行出具的资本支付证明；只有在公司注册完成之后，该托管限制才会被解除。

注资与解冻路径:

实缴资本规则: 根据韩国商业法，无需采取任何措施；不过，公司章程中规定的全部已发行股本必须在提交注册申请之前存入韩国的冻结银行托管账户，且必须随同申请文件一起提供银行出具的资本支付证明；只有在公司注册完成之后，该托管限制才会被解除。

董事会首期决议范本 (Pro-Forma First Board Resolution)
尤汉·霍萨公司首届董事会决议。鉴于尤汉·霍萨是一家根据韩国共和国商业法成立的有限责任公司；鉴于公司的公司章程已由初始股东和发起人正式签署并经过公证；鉴于公司的注册资本已全部认购，且已记录在注册申请中；鉴于商业法和注册程序要求公司在注册申请提交前后或立即设立企业银行账户、确定注册地址，并任命法定官员；同时，本决议中授权的所有行动均合法、符合公司宗旨，且符合公司及其股东的利益。因此，决定如下：  
1. 注册资本认购：公司记录在注册资本表及注册申请中的实收股本，连同任何股份溢价，由认购表格上指定的人员予以批准、确认，并宣布为完全认购且以现金支付。在必要时，首席执行官可与设立人共同核实托管银行发出的银行资金支付确认书，并将该确认书作为资本支付的法定证明提交给相关注册机构。  
2. 银行授权：公司应开设并维护企业银行账户，包括韩元运营账户、多货币账户以及Stripe、USDC等支付系统的所需结算账户，这些账户应由首席执行官选择的一家或多家持牌银行提供。首席执行官或其指定的董事有权签署所有账户开设文件、签名卡、网上银行授权书、货币控制声明及银行协议。  
3. 注册地址确认：公司章程及注册申请中所述的公司注册地址，被确认为公司的法定地址，用于发送通知、办理业务、税务登记及监管沟通。首席执行官有权签署并确认与该地址相关的租赁、服务及办公管理协议，并可以任命任何注册地址服务代理人。  
4. 法定官员任命：注册文件中指定的首席执行官被任命为公司的首席执行官。注册文件中指定的审计师，或根据商业法第312条要求的人员，被任命为法定审计师；如果公司符合法定审计师豁免条件，董事会将按法律规定确认该豁免。

外汇管制与央行政策诊断

经常项目兑换自由度

韩元属于可自由使用的货币，用于经常账户交易，采用通知制体系管理，而非用于常规贸易和服务支付的审批许可制度。对于向国内有限责任公司提供的资本投入，如股权出资，必须通过指定的外汇银行使用资本交易报告模块进行申报；申报后，资金将存入托管/结算账户，并可根据岸上韩元-美元市场汇率进行兑换。一旦企业能够证明股息来源、支付相应的15.4%公司预扣税或获得税收协定证明，并向银行提交支付报告，即可进行出口利润汇出。韩国没有针对出口收入设立的循环返还制度，但所有出口收入必须在法定期限内返回国内，而低于特定阈值的收入则可通过简化程序处理。实际上，限制兑换的关键并非法律层面，而是文件要求：外汇银行在处理股息、贷款偿还、资本回流或大型公司间转账时，需要提供资金来源证明、受益所有人信息、税务完成证明以及正确的BOK报告。非居民股东无法直接通过电汇方式转账，他们需要提供披露表格、实际受益人声明、合法外汇证明，以及与有限责任公司所宣称的业务目的相一致的证明。

出口外汇强制结汇要求

根据《外汇交易法》及其实施令，出口收入必须在合同日期或发货日期后的6个月内收取；在经指定外汇银行批准后，对于合法的贸易信用条款，这一期限可延长至18个月。并没有强制要求将出口收入按固定比例兑换为韩元的规定；实际操作要求是，所有出口收入必须通过韩国指定的外汇银行进行办理，并上报至外汇信息系统。只有在需要将资金兑换为韩元用于国内支付时，才进行兑换。按岸上市场汇率出售。

央行监管: 韩国银行（BOK）作为主要的货币和中央银行机构，依据外汇交易法与经济财政部（MOEF）共同管理；韩国海关服务处负责监管实物跨境货币流动，金融监督局（FSS）则对指定的外汇银行实施反洗钱/反恐融资（AML/CFT）监管。
