E-government filing portal

Eine ausländische Gesellschaft oder eine ausländische nicht ansässige Einheit, die eine koreanische Steuerpräsenz aufrechterhalten möchte, muss zunächst klären, ob sie in Korea einen inländischen Geschäftssitz (einen festen Geschäftssitz) besitzt. Falls sie einen inländischen Geschäftssitz besitzt, muss der Vertreter dieses Sitzes die standardmäßige Antragstellung auf Geschäftsaufnahme (NTS) beim Bezirkssteueramt einreichen, das das Sitzregister betreffend hat. Wenn die ausländische Gesellschaft keinen inländischen Geschäftssitz besitzt, aber koreanische steuerpflichtige Tätigkeiten oder koreanische Steuererklärungspflichten hat, muss sie gemäß dem Rahmengesetz über die nationale Steuer einen koreanischen Steuervertreter ernennen, wobei der Steuervertreter die Geschäftsaufnahme für die ausländische Gesellschaft beantragt.
