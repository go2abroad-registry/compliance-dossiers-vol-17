外汇管制自由度 韩国实行一种有管理的浮动汇率制度，并允许经常账户自由兑换；不过，韩元并非可以自由用于海外交易。进口冷冻牛肉/海鲜的韩国企业必须通过获得许可的外汇银行进行支付，并提供进口申报单及相关贸易文件。资本账户交易则须进行报告和登记：对韩国有限责任公司提供的外来资本投入必须向韩国贸易投资促进局或指定外汇银行报告，且必须在资金到账前完成外国直接投资备案。一旦这些资金到位，即可计入外币资本账户；将外币兑换成韩元是合法的，但具体信息由银行和韩国金融监督院记录。股息汇出则需要经过审计后的财务报表、税务结算以及企业注册证明，以符合税收协定要求；虽然没有永久性的限制，但银行会确保股息已按照韩国商业法计入留存收益。韩元并非可用于海外交易的货币，因此资金只能用于国内用途或通过允许的金融服务使用。即使在自由化政策下，韩国金融监督院仍有权采取审慎的宏观经济措施。

法定实缴资本与验资锁资账户流程 强制验资锁定

根据韩国商法，没有相关规定；成立Yuhan Hoesa公司不存在强制性的法定最低出资额要求。不过，拟定的5000万韩元出资额必须以公司名义存入国内临时收款账户，并在注册前提交银行出具的出资证明。对于批发进口企业来说，建议至少拥有3000万韩元的实际营运资金，以便进行食品进口业务核算及外汇银行尽职调查。根据韩国一般公司法，并不要求设立冻结的托管账户，但韩国银行可以在注册确认之前暂时冻结该账户。

注资与解冻路径: 消防法规定，须取得消防系统竣工验收证书、冷库存储场所的施工使用批准或占用许可，以及韩国劳动安全卫生局出具的工作场所安全批准。若氨制冷设备中制冷剂含量超过2,000公斤，则还需取得劳动部出具的工艺安全管理报告及安全检查证书。根据《民防基本法》规定，该公司须制定应急疏散计划，参加市政民防演习，并指定专门的灾害预防管理人员，负责经许可的冷链设施的灾害预防工作。

实缴资本规则: 根据韩国商法，没有相关规定；成立Yuhan Hoesa公司不存在强制性的法定最低出资额要求。不过，拟定的5000万韩元出资额必须以公司名义存入国内临时收款账户，并在注册前提交银行出具的出资证明。对于批发进口企业来说，建议至少拥有3000万韩元的实际营运资金，以便进行食品进口业务核算及外汇银行尽职调查。根据韩国一般公司法，并不要求设立冻结的托管账户，但韩国银行可以在注册确认之前暂时冻结该账户。

董事会首期决议范本 (Pro-Forma First Board Resolution)
余汉浩斯有限公司董事会第一次会议决议第2025-001号。在韩国首尔钟路23街21基5楼、公司注册地址举行的余汉浩斯有限公司董事会会议上，于2025年3月1日上午10点韩国标准时间召开，有所有董事出席，并由公司秘书记录会议内容。主席宣布，达到法定人数，且以下事项已列入议程。经过充分讨论后，以下决议获得一致通过并立即生效：

第一决议：初始资本认购与支付。董事会批准由初始成员按照会议记录附件A中规定的比例，认购5000个每单位10,000韩元的出资单元，共计50,000,000韩元作为初始资本。首席执行官负责将资金存入公司的国内指定账户，并从接收银行获取资金存入的凭证。在公司完成司法登记之前，不得进行任何资本返还、贷款、股息或出资提取操作。

第二决议：银行授权。董事会指定首尔新韩银行金融中心作为主要交易和外汇银行，授权开设活期账户、外币账户、循环进口信用证账户及贸易金融账户。首席执行官与财务总监共同负责执行银行业务、信用证申请、进口票据、收款指令以及与冷冻肉尸和海洋鱼类进口相关的其他财务或海关支付手续。

第三决议：注册地址确认。董事会正式确认位于韩国首尔钟路23街21基5楼的地址为公司的法定注册地址，以符合商业法要求。首席执行官被要求获得房东同意、公用事业确认、消防安全检查批准以及注册所需的其他法院或市政通知。

第四决议：法定官员任命。董事会任命附件A第一部分中列出的人员为首席执行官和代表董事；第二部分中列出的人员为财务和外汇董事；第三部分中列出的人员为法定审计师。这些代表有权签署所有注册、银行、海关和许可文件，如韩国法律要求，则需共同签名。董事会明确认可

外汇管制与央行政策诊断

经常项目兑换自由度

韩国实行一种有管理的浮动汇率制度，并允许经常账户自由兑换；不过，韩元并非可以自由用于海外交易。进口冷冻牛肉/海鲜的韩国企业必须通过获得许可的外汇银行进行支付，并提供进口申报单及相关贸易文件。资本账户交易则须进行报告和登记：对韩国有限责任公司提供的外来资本投入必须向韩国贸易投资促进局或指定外汇银行报告，且必须在资金到账前完成外国直接投资备案。一旦这些资金到位，即可计入外币资本账户；将外币兑换成韩元是合法的，但具体信息由银行和韩国金融监督院记录。股息汇出则需要经过审计后的财务报表、税务结算以及企业注册证明，以符合税收协定要求；虽然没有永久性的限制，但银行会确保股息已按照韩国商业法计入留存收益。韩元并非可用于海外交易的货币，因此资金只能用于国内用途或通过允许的金融服务使用。即使在自由化政策下，韩国金融监督院仍有权采取审慎的宏观经济措施。

出口外汇强制结汇要求

对于从韩国出口的商品，出口商须在货物出口清关之日起18个月内收汇，除非根据《外汇交易条例》第40条获得延期批准。法律并未规定强制性的结汇比例，即无需将固定比例的出口收入在交货时结汇为韩元；但出口收入必须全部回流并存入经批准的外汇银行账户，不得留存境外，除非事先获得MOEF/BOK的批准。出口商须至少保存基础贸易文件五年。由于该特定的优翰荷萨公司结构为进口公司，因此该规定适用于其未来任何出口业务或加工冷冻商品的再出口业务。

央行监管: 作为韩国的中央银行，韩国银行根据《外汇交易法》发挥着核心外汇管理职能；经济财政部则负责政策层面的监管工作，由韩国银行许可的指定外汇银行来开展受监管的外汇业务。

第7框 / 第6行 跨境关联方披露文件：国际交易报告、转让定价本地文件、主文件、关联方贷款登记、特许权使用费支付、服务费支付以及集团间存货采购。 披露所有超过法定门槛的跨境关联交易。应说明交易对方、选择成本加成法、转售价格法、成本加成法、可比性分析法或利润分割法的依据，以及可比性分析的逻辑，以及功能、资产和风险特征。仅进行常规分销、未涉及CIGA（跨境投资与集团活动）的韩国冷冻牛肉和海产品进口企业属于警示信号；若未能在法定期限内提交本地文件或主文件，公司将面临文件处罚和应税收入调整的风险。 根据《国家税收框架法》第47-2条和47-5条，延迟申报或未申报行为将引发额外税收负担：未申报则需缴纳未缴企业税的20%额外税款；提交虚假申报则处以10%的过失罚款；故意隐瞒或提供虚假发票则处以40%的欺诈罚款。此外，未支付税款时还需按日收取附加费，直至款项付清为止。未能妥善保存和提交转让定价相关文件也会面临单独处罚，如果被发现存在隐瞒行为，该处罚可与40%的罚款合并计算。根据《逃税者惩罚法》，刑事逃税行为可处以最高10年的监禁，并处以逃税金额三倍的罚款；负责人员还须被强制禁止旅行并冻结其资产。

转让定价与经济实质

主文档/本地文档门槛: 如果韩国实体在上一财年跨境关联方交易金额达到500亿韩元，则必须准备本地文件；当跨国合并集团收入达到1000亿韩元且韩国实体进行关联方交易时，则需要准备主文件；当跨境关联方交易超过5亿韩元时，必须在企业税务申报书中附上年度国际交易报告。此外，还需以韩语或英语保存单独的转让定价文件，并在国家税务局提出要求后45天内提交。

经济实质审查范围: 韩国的经济实质法规及核心收入产生活动分析，依据《国家税收框架法》以及反滥用税法中的实质重于形式原则适用。对于冷冻牛肉和海产品的批发进口商而言，韩国实体必须证明其在韩国实际履行采购谈判、订单接受、冷链库存风险管控、温度管理、销售合同签订、保险以及外汇风险管理工作，并配备实质性的人员和场所。若该韩国实体仅为开票空壳，上述核心收入产生活动由境外关联方实际执行，则韩国国家税务局将重新分配收入、拒绝适用税收协定优惠、对实质分红征收预提税，并对违反独立交易原则的行为处以处罚。

致命合规红线与董事个人责任

逃税与虚假报税

法定制裁: 《逃税者惩罚法》第3条及《国家税收框架法》第47-2、47-3和47-5条：通过欺诈性少报收入的行为，需额外缴纳被逃税金额的40%作为税款；可处以相当于逃税金额三倍的刑事罚款，并可判处不超过10年的监禁。

董事个人责任: 根据韩国商业法第401条，企业伪装行为被揭露后，故意或恶意参与逃避税务责任的董事需对公司的税务损失承担个人及连带责任，并负责归还被转移的企业资产。国家税务局可以实施旅行禁令，将相关董事列入黑名单，作为违法纳税人予以处罚，直至其完成税务赔偿为止；而因税务欺诈而被定罪的话，最高可判处10年的监禁。
转移定价操纵与文件缺失

法定制裁: 《国际税收事务协调法》第11条允许国家税务机构将应纳税收入调整为公平交易金额；对不实的申报行为可处以10%至40%的罚款，而未能提供转让定价文件则会导致额外的文件提交要求和证据制裁，包括取消纳税人的比较性证据资格。

董事个人责任: 批准虚假内部交易定价的董事，需就商业法第401条规定的调整后企业所得税承担民事赔偿责任；若其将资金或资产转移至境外以逃避追偿，可能被列为共同责任人。NTS对重大税款滞纳的公司董事实施资产冻结、旅行禁令及公开黑名单制度；对于虚假申报国际交易的，可处以最高五年监禁及高额罚款的刑事处罚。
空壳公司与税收协定滥用 / 缺乏经济实质

法定制裁: 国家税务局采用OECD BEPS MLI主要目的测试标准以及韩国一般反滥用原则，以拒绝享受条约优惠，将中间机构重新定义为韩国实体的透明代理人，对构建性股息或特许权使用费征收22%的合并预提税，并对遗漏行为处以40%的欺诈所得罚款。

董事个人责任: 策划设立空壳公司并通过虚假中间机构进行资金转移的董事，将面临揭开公司面纱的法律追责：其需对未缴的公司税、预提税及滞纳金承担连带和按份责任。国家税务署将把相关董事列入黑名单，实施财产冻结和旅行禁令，并依据《逃税处罚法》将其移送刑事追责；故意、屡次逃税可被判处十年以上有期徒刑，同时将依法追缴被转移的公司利润，责令其承担民事赔偿责任。
