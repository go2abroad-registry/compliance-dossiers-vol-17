22 % (20 % nationale Dividendenabzugsteuer + 2 % lokale Einkommensteuererhöhung) an Bruttodividenden, die von einer koreanischen Gesellschaft an einen nicht ansässigen corporate-Aktionär gezahlt werden, es sei denn, sie werden durch ein geltendes Doppelbesteuerungsabkommen (DBA) verringert.
