商业开户与资金池

商业开户与外汇资金池

央行经常项目外汇管制诊断、本土商业大行与离岸数字EMI矩阵、拒单痛点防御指南。

外汇管制自由度 韩元可以在经常账户中兑换；与贸易相关的和普通服务支付则被放开，可以通过外汇银行进行汇款，但需履行报告义务。资本账户交易，包括股权注入、贷款以及当地资产收购等，通常都是允许的，但需要事先申报、按用途分类报告，并提供相应的证明文件。外国企业可以将美元或其他外币按当前市场汇率兑换成韩元，不过韩元并非在指定市场之外的国际可兑换货币；离岸交易主要集中在NDF中，因为韩元结算只能在许可的国内银行进行。利润和股息的汇出可在缴纳了企业税和预提税之后进行；付款银行需要提供经审计的财务报表、董事会决议、税务支付证明，如适用，还需提供税务条约居住证明，以降低法定的22%预提税率。因此，该制度虽然允许经常账户自由兑换，但对资本回流却设置了一定的合规要求，而非完全禁止。资金安排应依靠许可的韩国外汇银行进行所有兑换操作，避免使用离岸韩元流动性池。

法定实缴资本与验资锁资账户流程 强制验资锁定

根据《商业法》，Yuhan Hoesa（有限责任公司）没有法定的最低实收资本要求；不过，必须发行至少一股股份，且所有认购的资本金额必须在注册日期之前以现金形式完全实收。资本必须转入公司在韩国持牌金融机构中设立的指定托管账户，银行出具的余额证明也必须提交给注册法院。如果使用实物资本，则必须由法院指定的评估员进行估价，并在注册前实际交付。非居民股东可以提供外币作为资本，但必须通过韩国外汇银行将资金汇回本国，并遵守《外汇交易法》的相关规定。

注资与解冻路径: 不适用——该业务属于办公/数据服务领域，并非高层化学或制造场所。如果公司出租一个小型办公室空间，必须从当地国家消防局获得基本的灭火检查证书以及简单的消防系统操作检查表；此外，如果员工人数达到相关标准，还必须向韩国职业安全与健康局登记工作场所信息，并任命一名工作场所安全经理。无需办理复杂的民防认证。

外汇管制与央行政策诊断

经常项目兑换自由度

韩元可以在经常账户中兑换；与贸易相关的和普通服务支付则被放开，可以通过外汇银行进行汇款，但需履行报告义务。资本账户交易，包括股权注入、贷款以及当地资产收购等，通常都是允许的，但需要事先申报、按用途分类报告，并提供相应的证明文件。外国企业可以将美元或其他外币按当前市场汇率兑换成韩元，不过韩元并非在指定市场之外的国际可兑换货币；离岸交易主要集中在NDF中，因为韩元结算只能在许可的国内银行进行。利润和股息的汇出可在缴纳了企业税和预提税之后进行；付款银行需要提供经审计的财务报表、董事会决议、税务支付证明，如适用，还需提供税务条约居住证明，以降低法定的22%预提税率。因此，该制度虽然允许经常账户自由兑换，但对资本回流却设置了一定的合规要求，而非完全禁止。资金安排应依靠许可的韩国外汇银行进行所有兑换操作，避免使用离岸韩元流动性池。

出口外汇强制结汇要求

根据《外汇交易法》，出口收入由韩国授权的外汇银行进行收取；对于商品而言，常规的法定结算期限为出口申报之日起90天，除非获得延期付款的批准；而服务或API收入则按照发票规定的付款日期进行结算。没有强制性的资金返还比例要求；出口商可以将全部收益存入外币账户，或自由兑换为韩元。每一笔收入都必须在30天内由银行通过电子外汇报告系统进行申报。

税表逐栏填报拆解（非居民核心栏目）

栏号字段 非居民填报指引避税陷阱
框1（总收入/业务收入） 来自网络爬虫和代理API网关业务的全球总收入，包括订阅费、基于使用量的API费用以及附属的集成服务。 韩国注册的优翰霍萨公司对其全球收入征税。对于非居民拥有的资本，必须申报全部收入，不得进行任何离岸分配，除非已签订预约定价协议或具备有效转让定价文件以支持境外利润分割。 逾期申报将导致未缴税款处以20%的过失罚款（一般无意遗漏为10%）。逾期付款的利息自应缴日期起按每月1.8%计算。若存在故意少报，且金额超过韩元3亿韩元或总税额的30%，将依据《逃税处罚法》追究刑事责任，最高可判处10年有期徒刑，并处以最高不超过所逃税款五倍的罚款。
框2（不可抵扣费用/关联方费用） 针对支付给境外关联方的过高管理费、技术 royalty、佣金分成及娱乐费用的加回表。 任何支付给离岸母公司或关联实体的特许权使用费或服务费，均须按照独立交易原则进行审查。如果受益方缺乏实际的职能和经济实质，该支付将被禁止作为税前扣除项目，并被重新归类为隐性股息，适用22%的预提税。 逾期申报将导致未缴税款处以20%的过失罚款（一般无意遗漏为10%）。逾期付款的利息自应缴日期起按每月1.8%计算。若存在故意少报，且金额超过韩元3亿韩元或总税额的30%，将依据《逃税处罚法》追究刑事责任，最高可判处10年有期徒刑，并处以最高不超过所逃税款五倍的罚款。
框3（在考虑亏损结转前计算的应税收入） 在应用所有法定加回项目和排除项目后、在考虑净经营亏损抵免之前，可调整的应税收入。 对于非居民拥有的韩国有限合伙企业，若债务与权益比率超过2:1，薄资本化规则将禁止向境外控股股东支付利息。任何超出部分的利息必须重新分类为实质性的股息。 逾期申报将导致未缴税款处以20%的过失罚款（一般无意遗漏为10%）。逾期付款的利息自应缴日期起按每月1.8%计算。若存在故意少报，且金额超过韩元3亿韩元或总税额的30%，将依据《逃税处罚法》追究刑事责任，最高可判处10年有期徒刑，并处以最高不超过所逃税款五倍的罚款。
第4栏（亏损结转抵扣） 利用前一年度《税前亏损结转表》中列示的前一年度经营亏损。 普通企业只允许保留5年的结转额。亏损必须以审计过的账簿作为证明，而所有权连续性并非法定要求；但如果收购行为没有合理的商业目的，那么在非居民资本注入之前所遭受的亏损则可能被拒绝认可。 逾期申报将导致未缴税款处以20%的过失罚款（一般无意遗漏为10%）。逾期付款的利息自应缴日期起按每月1.8%计算。若存在故意少报，且金额超过韩元3亿韩元或总税额的30%，将依据《逃税处罚法》追究刑事责任，最高可判处10年有期徒刑，并处以最高不超过所逃税款五倍的罚款。
第5栏（税收抵免与外国税款抵免） 外国税收抵免、研发税收抵免和投资税收抵免的计算。 韩国的由外国股东拥有的公司，可就其来源于境外的收入所缴纳的税款申请境外税额抵免。该抵免额度限于与该境外收入相关的韩国企业所得税。抵免所需证明材料包括经翻译成韩语并经 apostille 认证的税务评估文件。 逾期申报将导致未缴税款处以20%的过失罚款（一般无意遗漏为10%）。逾期付款的利息自应缴日期起按每月1.8%计算。若存在故意少报，且金额超过韩元3亿韩元或总税额的30%，将依据《逃税处罚法》追究刑事责任，最高可判处10年有期徒刑，并处以最高不超过所逃税款五倍的罚款。
第6项（对非居民被动收入的预提税） 东京公司（或其他境外）股东从韩国实体获得股息、利息或版税时，就其应承担的公司预提税义务所作的声明。 韩国有限责任公司必须将股息、利息和特许权使用费中 22% 的部分扣留在非居民实益拥有人手中，除非符合双重征税协定规定的减免条件。扣税情况需按照《征收规则》规定的日期，通过第 23-1 号表格（非居民扣税表）进行申报和缴纳。 逾期申报将导致未缴税款处以20%的过失罚款（一般无意遗漏为10%）。逾期付款的利息自应缴日期起按每月1.8%计算。若存在故意少报，且金额超过韩元3亿韩元或总税额的30%，将依据《逃税处罚法》追究刑事责任，最高可判处10年有期徒刑，并处以最高不超过所逃税款五倍的罚款。

转让定价与经济实质

主文档/本地文档门槛: 年营收为1000亿韩元——那些关联方跨境交易金额超过500亿韩元的企业，必须准备并提交本地文件和主文件；对于标准的小型企业Yuhan Hoesa来说，公司间交易的文档更新门槛分别为500亿韩元（同一国家关系下的交易）和1000亿韩元（跨境控制交易，如果年营收低于1000亿韩元，则适用简化/实时审计文档要求）。

经济实质审查范围: 尽管韩国并未设立类似阿联酋的经济实质法规（ESR）制度，但《国家税收基本法》第14条适用实质重于形式的原则。对于跨境API网关公司而言，韩国实体必须证明其管理决策、服务器运营、客户合同、账单系统以及数据处理员工均位于韩国。如果该实体仅为空壳公司，其实际产生收入的经营活动位于无税收管辖地，则韩国税务机关可能重新认定其安排，并对实际利润的穿透征收税款。

致命合规红线与董事个人责任

逃税 / 未申报收入

法定制裁: 逃税处罚法第九条——处以最高十年监禁，并处以最高为逃避税额五倍的罚款；若故意逃税金额超过100亿韩元，罚款金额不得低于所逃避的税额。

董事个人责任: 当董事忽视内部控制或利用节税结构为自己牟利时，将揭开公司人格。董事将对未缴的公司税款及罚金累计承担连带和个别责任（《国家税收基本法》第39条）。国家税务机关可禁止其出境（旅行禁令）、冻结其个人银行账户以及查封其个人财产。可对其处以最高法定刑期的监禁，同时并处刑事罚款及民事赔偿。
资本弱化及隐性股息滥用

法定制裁: 韩国税收程序法第54条（资本弱化规则）——将利息重新定性为不可抵扣的分配，重新计算企业所得税，并对重新定性的利息征收22%的预提税；若未申报预提税，额外加征20%的罚款；若涉及欺诈行为，还将依据逃税处罚法承担行政及刑事责任。

董事个人责任: 签署贷款协议或设计融资安排的董事，需对重新定性股息所涉的税款及任何刑事罚款承担个人责任。国家税务署（NTS）可对董事实施旅行禁令，并对其持有的不动产、汽车及证券实施查封。若该董事依据《逃税处罚法》第9条被定罪，将处以1至10年有期徒刑，并处以最高不超过故意逃避税额五倍的罚款。
反洗钱/未获许可的虚拟资产收款

法定制裁: 《韩国反洗钱法》《特定金融信息报告与使用法》第17条——未经许可从事支付服务提供商（VASP）业务的，处五年以下有期徒刑或最高罚款5亿韩元；根据《国家税收基本法》规定，逃避所得税的，处未申报金额40%的罚款。

董事个人责任: 由于董事拥有并控制韩国优翰霍萨公司，韩国国家银行与金融监督局（NTS和FSS）将该实体视为用于规避报告义务的透明性通道。该董事将因洗钱、罚款及非法所得没收而承担个人刑事责任。若董事利用该实体作为掩护以隐藏其自身的加密货币套利行为，根据《基本法》，法院可穿透公司法人面纱；该董事可能被韩国金融情报单位（KoFIU）列入黑名单，受到跨境汇款限制，且在刑事调查期间被禁止出境。韩国法院已判例确认，通过未实施KYC/反洗钱程序的空壳公司转移加密货币收益的行为，可判处董事最高五年监禁及5000万韩元罚款。
