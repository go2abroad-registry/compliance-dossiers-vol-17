商业开户与资金池

商业开户与外汇资金池

央行经常项目外汇管制诊断、本土商业大行与离岸数字EMI矩阵、拒单痛点防御指南。

外汇管制自由度 韩国拥有一套具有法律约束性但运作高效的外汇管制体系。诸如软件出口收入、技术服务费、特许权使用费以及日常运营费用等经常账户交易，可以通过被指定为外汇银行的银行进行自动转换。支付指令需要明确的目的、相关发票或合同，以及合理的资金来源或用途证明，但对于大多数正当的服务交易则无需事先审批。资本账户交易则受到更为严格的限制：非居民股东向Chusik Hoesa公司投入资本时，必须通过指定的外汇银行完成外国直接投资报告，获得外国直接投资注册确认书，并提供SWIFT汇款凭证。韩元并非一种可以自由用于投机或纯粹资本账户转移的货币。通过股息或清算分配获得的利润，只有在银行审核了经审计的财务报表、预扣税支付凭证以及原始外国直接投资注册记录后，才能作为经常账户款项进行支付。出口收入则无需强制转换为韩元，企业可以保留外币存款账户中的硬货币。主要的合规问题在于确保每一笔进出款项都对应着已批准的用途代码，并且相关文件与国际操作规范及AI LLM API收入模型保持一致。

法定注册代理人与物理地址 强制持牌代理

韩国商业注册要求提供明确的街道地址，而公司章程中必须注明总部所在的城市、县或区；对于Chusik Hoesa公司来说，仅有一个商业邮箱并不具备注册所需的地址条件。对于这种AI/LLM API令牌业务，国家税务局要求有实体经营场所以进行增值税和企业所得税申报，因此会严格审查那些看似只是用于邮件转寄的地址。大多数韩国银行拒绝为外国企业开设企业账户时使用纯虚拟办公室，而是要求有正式的租赁合同、水电费账单、标识牌或现场分支机构访问记录。具有正式租赁合同、楼层规划及公司铭牌的服务式办公室或共享办公室是可行的；而独立的虚拟邮箱则不被推荐，很可能会被拒绝。

外汇管制与央行政策诊断

经常项目兑换自由度

韩国拥有一套具有法律约束性但运作高效的外汇管制体系。诸如软件出口收入、技术服务费、特许权使用费以及日常运营费用等经常账户交易，可以通过被指定为外汇银行的银行进行自动转换。支付指令需要明确的目的、相关发票或合同，以及合理的资金来源或用途证明，但对于大多数正当的服务交易则无需事先审批。资本账户交易则受到更为严格的限制：非居民股东向Chusik Hoesa公司投入资本时，必须通过指定的外汇银行完成外国直接投资报告，获得外国直接投资注册确认书，并提供SWIFT汇款凭证。韩元并非一种可以自由用于投机或纯粹资本账户转移的货币。通过股息或清算分配获得的利润，只有在银行审核了经审计的财务报表、预扣税支付凭证以及原始外国直接投资注册记录后，才能作为经常账户款项进行支付。出口收入则无需强制转换为韩元，企业可以保留外币存款账户中的硬货币。主要的合规问题在于确保每一笔进出款项都对应着已批准的用途代码，并且相关文件与国际操作规范及AI LLM API收入模型保持一致。

第46条（受控外国公司收入） 韩国居民/股东持有的低税辖区受控外国公司收入包含问题。 如果任何非居民股东控制了一家处理与人工智能相关的知识产权或许可的境外子公司，则需进行分层受控外国企业（CFC）计算；该境外公司不得因实际业务活动门槛而被排除。 逾期或未申报：未缴纳法定税款将面临20%的过失附加费；少报税款则面临10%的附加费；虚假或欺诈性申报则面临40%的附加费（根据《国家税收框架法》第47-2条/47-3条）。未支付的款项将按0.022%的利率计算每日利息。根据《税务犯罪处罚法》，逃税或虚假申报行为可处以最高10年的监禁，以及最高为逃税金额的3倍的罚款，此外还可能导致企业被禁止旅行并被列入公开黑名单。

转让定价与经济实质

主文档/本地文档门槛: 总计10,000,000,000韩元的跨境关联方交易；主文件及本地文件必须在财年结束后9个月内提交给NTS，且年度转移定价报告需随企业税务申报文件一同提交。

经济实质审查范围: 没有单独的经济实体法规，但韩国遵循OECD BEPS的实益所有权和实质重于形式原则；接受条约减缩预扣税的企业必须在韩国开展核心收入生成活动，包括合同谈判、定价、人工智能模型开发管理、服务器容量风险控制以及信用管理等事务，这些活动需以工资发放、办公设施、董事会会议记录及业务文件作为支撑。

致命合规红线与董事个人责任

逃税及虚假企业报税

法定制裁: 《税务违法处罚法》第3条：可处以10年以下监禁和/或相当于逃税金额3倍的罚款；根据《国家税收框架法》第47-3条：需缴纳40%的虚假申报附加费；如果逃税金额超过税务犯罪阈值，则必须将其移交刑事部门处理。

董事个人责任: 如果隐匿或披露失败，且公司缺乏资金流动性，董事需共同承担未支付的企业税、利息及罚款责任。刑事法院可判处个人监禁，而公司则无法获得豁免；NTS可以将该公司及签署文件的董事列入黑名单，下达旅行禁令，冻结个人海外账户，并要求公司在清算前退还被侵占的资金。
转让定价不合规及文件欺诈

法定制裁: 《国际税收调整法》第5条：重新确定应税收入及调整公平交易价格；对收入调整额外征收20%的附加税；若缺乏必要的文件证明，将面临40%的欺诈附加税以及OCR相关处罚；如果提交的是虚假的转让定价文件，则构成隐匿行为，需承担刑事责任。

董事个人责任: 签署申报表并明知提交虚假转让定价文件的董事被视为共同共犯；可依据韩国民法第750条（侵权行为）被责令赔偿公司及第三方股东，并被禁止担任其他董事会职位；通常会附加旅行限制和个人资产查封措施，以确保未支付的罚款得以清偿。
空壳公司 / 反洗钱受益所有权滥用

法定制裁: 《外国投资促进法》和《特定金融信息法》要求全面披露实际受益所有权；虚假申报将面临最高1亿韩元的罚款、外国投资资格被取消，以及拒绝所有条约优惠。反洗钱监控措施将暂停付款，向金融情报单位（FIU）报告将触发刑事处罚。

董事个人责任: 签署人或主要所有者可能需对虚假的受益所有权声明承担个人责任：根据金融法律，可处以最高5年的监禁和最高5000万韩元的罚款。法院可以揭开公司的面纱，冻结个人资产，实施旅行禁令（列入黑名单），要求民事赔偿给税务机关和第三方债权人，并在被定罪后判处刑事监禁。
