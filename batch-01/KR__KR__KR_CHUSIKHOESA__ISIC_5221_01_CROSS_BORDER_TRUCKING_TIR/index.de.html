24 % nationale Unternehmensertragssteuer (USt) plus 10 % lokale Ertragssteuerzuschlag auf die nationale USt, was eine kombinierte maximale Grenzsteuersatz von 26,4 % ergibt

Dividend withholding tax (WHT)

20 % staatliche Unternehmensabgabensteuer sowie eine zusätzliche lokale Einkommensteuer von 10 % auf die staatliche Abgabensteuer, was eine insgesamt staatliche Abgabenlast von 22 % für Dividendenverteilungen, die von einem koreanischen Chusik Hoesa an einen nichtansässigen Unternehmensaktionär ausgeschüttet werden, ergibt.
