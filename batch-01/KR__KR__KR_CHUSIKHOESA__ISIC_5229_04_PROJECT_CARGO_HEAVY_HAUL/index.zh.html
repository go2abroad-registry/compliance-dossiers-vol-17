外汇管制自由度 韩国实行一种受管理的浮动外汇制度。韩元可以在各种账户交易中自由兑换，包括与贸易相关的支付、股息、服务费用以及利息支付等，但必须通过国内外汇银行进行验证。资本账户交易则相对较为自由，不过某些汇款仍需根据《外汇交易法》进行报告、登记或审批；对Chusik Hoesa公司的外国直接投资则通过《外国投资促进法》进行记录。没有强制性的出口兑换比例要求；出口商可以将外币存放在指定的外汇存款账户中，并随时进行兑换。利润汇出则主要依赖文件证明：银行必须收到经审计的财务报表、相应的预扣税支付证明、决定股息的股东大会记录以及税务结算证明后，才能办理股息汇出业务。外汇汇率由市场自由确定，通过授权银行可以进行对冲操作。非金融企业的投机性外汇交易受到限制，短期外部借款则需遵守相关报告和货币政策规定。总体而言，韩国提供了高度可兑换、制度透明的环境，非常适合跨境项目货物运输业务。

跨境出口 0% 零税率申报条件

当韩国增值税注册企业将商品从韩国出口到国外目的地，并保留符合海关要求的出口证明时，即可享受0%增值税的免费服务。为出口重货和特殊货物直接提供的项目-货物物流服务被视为与出口直接相关的服务，同样享受零税率优惠。只要服务发票上明确注明了相关出口货物、购买方以及服务费用，且服务费用由外币支付或结算，则符合这一条件。如果不存在实际出口行为，那么根据供应地规则，如果接收方位于韩国境外，且韩国供应商能够证明相关服务是在海外提供的，并且资金也是从国外获得的，则仍可能适用零关税政策。

  • 韩国海关出口申报（出口清关证书）显示UNI-PASS电子申报编号及出口物品描述
  • 原提单、海运提单或空运提单，证明超限货物从韩国实际出发
  • 商业发票及装箱单，需注明超限尺寸、重量、标记和项目货物描述
  • 货运代理或项目货物服务合同，证明零税率服务与出口货物之间的直接关联
  • 由经授权的外汇银行出具的外汇购销凭证，或显示以外币计价的出口收入已入账的银行汇款证明
  • 超出规定尺寸的运输许可、路线勘察，或根据需要由有关道路或港口主管部门出具的特殊运输批准，以证明出口运输的合法性

经增值税注册的经营者必须通过 NTS HomeTax 电子发票服务开具电子税务发票，并在交付日期后的第二天通过 HomeTax 网络界面、批量文件协议或机器对机器 API 将发票数据传输给 NTS。韩国不采用预审批财政盖章模式；相反，NTS通过已开具和收到的税务发票数据、增值税申报单、海关报关单以及外汇结算数据的实时数据库匹配来审核发票。延迟、错误或遗漏的电子传输行为将按规定的法定税率征收增值税附加税。

当NTS或韩国海关部门拒绝认可零税率证明时，该供应品将被重新归类为需缴纳税项商品，并按全额供应价值征收10%的增值税；此外，还需缴纳根据《国家税收框架法》规定的因申报不真实或欺诈行为而产生的额外税款以及迟付利息。任何虚假的出口增值税退税申请都会被追回，并附加高达40%的惩罚性加费；对于故意逃避纳税的行为，相关董事和税务代表将依据《税务违法者处罚法》承担刑事责任。如果出口申报或提单是虚假的，还可能面临海关虚假申报处罚和出口限制制裁。

韩国实行一种受管理的浮动外汇制度。韩元可以在各种账户交易中自由兑换，包括与贸易相关的支付、股息、服务费用以及利息支付等，但必须通过国内外汇银行进行验证。资本账户交易则相对较为自由，不过某些汇款仍需根据《外汇交易法》进行报告、登记或审批；对Chusik Hoesa公司的外国直接投资则通过《外国投资促进法》进行记录。没有强制性的出口兑换比例要求；出口商可以将外币存放在指定的外汇存款账户中，并随时进行兑换。利润汇出则主要依赖文件证明：银行必须收到经审计的财务报表、相应的预扣税支付证明、决定股息的股东大会记录以及税务结算证明后，才能办理股息汇出业务。外汇汇率由市场自由确定，通过授权银行可以进行对冲操作。非金融企业的投机性外汇交易受到限制，短期外部借款则需遵守相关报告和货币政策规定。总体而言，韩国提供了高度可兑换、制度透明的环境，非常适合跨境项目货物运输业务。

出口外汇强制结汇要求

根据外汇交易规定，出口收入必须在出口申报日期起6个月内收取；外汇银行可根据相关理由再延长6个月。没有强制兑换要求，也没有最低韩元兑换比例要求；企业可以将所有外币金额存入持牌韩国银行的外汇存款账户，随后按市场汇率进行兑换，或直接用于支付外币款项。提前收到的出口收入必须在规定期限内与相应的出口申报单进行结算；清算后剩余的余额可以保留或转换为其他形式。若未能在法定期限内完成结算，则需向韩国银行提交额外报告，这可能会影响出口商的贸易合规状况。

转让定价与经济实质

主文档/本地文档门槛: 总计达100亿韩元的国际关联方交易需要同时进行本地文件和主文件准备工作；收入达到1000亿韩元或以上的跨国企业还必须编制各国报告。低于交易门槛的企业仍须在年度企业税务申报表中披露其国际交易情况。

经济实质审查范围: 韩国没有正式的“经济实体注册制度”，但国家税务机构依据《国际税收事务协调法》第3条和《框架法》第14条，采用“核心收入生成活动”分析原则以及“实质重于形式”原则来进行监管。负责运营海外项目的中韩企业必须设立韩国董事会，在韩国开设银行账户及车辆/合同相关文件，雇佣当地的项目工程师和商务人员，并在韩国进行决策；不具备这些功能的实体将被视为空壳公司，其利润将归属于外国实际所有者。

致命合规红线与董事个人责任

故意不缴纳非居民股息预扣税并予以免除

法定制裁: 根据《国家税收框架法》第66条，评估未支付的全额22.0%预提税以及40.0%的欺诈性遗漏处罚税，并加收每日迟缴利息；付款方被视为唯一承担预提税义务的代扣代缴义务人，不得将该责任转嫁给境外股东。

董事个人责任: 批准分配的代表董事和董事会成员根据《框架法》第39条对所计算的税款承担连带责任；超过严重欠税阈值的未缴国家税款将触发旅行黑名单制度。根据《税务违法处罚法》，涉及犯罪行为的移交可能面临最高5年的监禁以及最高1亿韩元的罚款。

法定制裁: 国家税务机构可根据《国际税收事务协调法》第13条重新确定公平交易价格，调整应纳税收入，取消无依据的扣除项目，对于疏忽性低估行为可处以20.0%的罚款；对于故意或操纵性低估行为则处以40.0%的罚款，此外还加收迟付利息。

董事个人责任: 若董事伪造交易文件或忽视税务顾问的反避税警告，可能根据连带责任条款被个人追缴公司应缴的税款；持续伪造文件可构成加重的逃税行为，最高可被判处五年监禁并没收个人财产。
空壳公司运营及避免双重征税协定/税收协定滥用（经济实质缺失）
