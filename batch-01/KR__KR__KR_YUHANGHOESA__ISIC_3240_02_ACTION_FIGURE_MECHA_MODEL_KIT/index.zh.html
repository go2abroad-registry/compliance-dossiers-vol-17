央行经常项目外汇管制诊断、本土商业大行与离岸数字EMI矩阵、拒单痛点防御指南。

外汇管制自由度 根据《外汇交易法》，韩国实行自由化的经常账户制度。韩国银行和经济财政部通过外汇信息系统实施审慎监管。在进出口商业结算中，支付和收款无需得到中央银行的单独批准，但对于超过法定额度的汇款，尤其是资本账户交易，则需要通过银行渠道进行交易申报。资本账户交易已逐步实现自由化，通常只需向指定的外汇银行报告或提交相关文件，无需中央银行的预先批准。外来直接投资流入必须在资金汇出之前或之后立即根据《外国投资促进法》进行报告，且所得资金必须存入指定的外国投资存款账户，直至资本验证完成为止。如股息和留存收益分配等利润汇出属于经常账户支付；从技术上讲这些款项可以自由兑换，但付款银行会要求提供股息批准文件、经审计的财务报表、税务证明以及投资者持股记录。出口收入不必强制出售给中央银行；出口商可以将外币存储在国内的外汇银行账户中，但必须遵守结算和收款期限，且流入资金必须通过外汇信息系统进行报告。任何兑换为韩元的行为均按当前市场汇率执行。

法定注册代理人与物理地址 强制持牌代理

对于从事高精度塑料注塑成型业务（ISIC 3240）的有限责任公司，仅使用纯虚拟办公地址或商业邮箱是不可接受的。国家税务局要求必须设有能够储存生产记录并开具税务发票的固定经营场所。韩国银行也因无法进行实地尽职调查，将拒绝将虚拟办公地址作为唯一的注册地址。配备独立私人单元、独立格栅入口以及可提供设备存放证明的共享办公空间，在特定条件下可被接受，但必须补充提供当地分租证明、平面图以及实际使用证明文件。市政消防委员会将要求每年进行一次消防检查并取得批准。因此，虚拟办公地址仅可作为过渡性安排，公司须在注册成立后90天内租赁实际的工厂或办公场所。

法定实缴资本与验资锁资账户流程 强制验资锁定

没有已缴纳资本的最低限制。韩国商业法并不要求Yuhan Hoesa拥有最低资本，也不强制设立国家托管账户。如果相关法规规定了注册资本要求，那么资本必须在法院注册之前全部认购并实际支付。非居民创始人通常通过外国投资账户进行出资，韩国银行会出具出资凭证；银行可能会要求提供反洗钱资金来源证明，并将资金存放在受限交易账户中，直到企业注册完成为止。

注资与解冻路径:

实缴资本规则: 没有已缴纳资本的最低限制。韩国商业法并不要求Yuhan Hoesa拥有最低资本，也不强制设立国家托管账户。如果相关法规规定了注册资本要求，那么资本必须在法院注册之前全部认购并实际支付。非居民创始人通常通过外国投资账户进行出资，韩国银行会出具出资凭证；银行可能会要求提供反洗钱资金来源证明，并将资金存放在受限交易账户中，直到企业注册完成为止。

董事会首期决议范本 (Pro-Forma First Board Resolution)
由董事会一致书面同意代替正式会议通过的尤汉霍萨有限公司董事会决议

鉴于尤汉霍萨根据韩国商业法作为有限责任公司设立，其公司章程需提交给相关地方地区法院登记处备案；

鉴于公司章程规定了授权资本单位，初始成员已全额认购所有已发行资本，且章程中指定的董事已接受其职务；

鉴于董事需通过验证资本缴纳、选定注册地址、开设企业银行账户以及获得所有工业与物理许可来完成法定设立程序。

因此，决定如下：

1. 资本认购与缴纳。董事会确认各成员已按照公司章程认购了已发行资本单位。企业代表应核实款项已全部存入企业账户，且已支付金额仅用于企业用途。

2. 银行授权。企业代表和首席财务官可单独处理不超过5万美元的支付事务，共同处理超过5万美元的支付事务，有权开设并管理企业结算及外币账户，办理SWIFT电汇业务，签署支付指令，任命网上银行管理员，并建立PayPal及其他低风险支付渠道。

3. 注册地址。公司的注册地址及法律所在地应为公司章程中规定的地址。企业代表有权签订办公室和工厂租赁合同，向法院和国税局登记该地址，并管理所有实体设施的相关事宜。

4. 法定官员任命。董事会任命第一份名单中的人员为董事总经理和企业代表、首席财务官、合规官和企业秘书，任期至下一次成员大会为止。

5. 企业印章与记录。企业秘书负责制作并登记企业印章，维护会员登记簿、会议记录簿、会员清单及所有法定记录，并将印章登记文件提交给地区法院。

6. 工业与物理许可。董事会指示管理层执行第二阶段许可计划，包括工厂设立审批、环境预评估或完整的EIA报告、消防安全与民防许可以及职业安全批准，在任何生产活动开始之前

外汇管制与央行政策诊断

经常项目兑换自由度

根据《外汇交易法》，韩国实行自由化的经常账户制度。韩国银行和经济财政部通过外汇信息系统实施审慎监管。在进出口商业结算中，支付和收款无需得到中央银行的单独批准，但对于超过法定额度的汇款，尤其是资本账户交易，则需要通过银行渠道进行交易申报。资本账户交易已逐步实现自由化，通常只需向指定的外汇银行报告或提交相关文件，无需中央银行的预先批准。外来直接投资流入必须在资金汇出之前或之后立即根据《外国投资促进法》进行报告，且所得资金必须存入指定的外国投资存款账户，直至资本验证完成为止。如股息和留存收益分配等利润汇出属于经常账户支付；从技术上讲这些款项可以自由兑换，但付款银行会要求提供股息批准文件、经审计的财务报表、税务证明以及投资者持股记录。出口收入不必强制出售给中央银行；出口商可以将外币存储在国内的外汇银行账户中，但必须遵守结算和收款期限，且流入资金必须通过外汇信息系统进行报告。任何兑换为韩元的行为均按当前市场汇率执行。

出口外汇强制结汇要求

根据外汇交易法规，出口索赔必须在相关出口销售合同规定的付款期限内进行结算，通常最迟应在出口日期起180天内完成，除非负责处理外汇业务的银行为已记录的未结账户情况延长了期限。延期支付或海外委托交易安排。出口收入没有强制性的韩元兑换比例要求；实际交还比例为0%，即出口商可以将所有外币收入存入有资质的外汇银行的外币存款账户，或按市场价格出售给该银行。所得款项必须存入韩国实体持有的国内外汇账户中，且必须通过外汇信息系统进行报告，与出口商的海关申报单、发票及银行信用证明进行匹配。未能在规定的期限内完成结算，将使该实体面临罚款、追收命令以及未来交易支付方面的行政障碍。

央行监管: 韩国银行（BOK）通过外汇交易法框架运作；经济财政部长官负责整体外汇政策监督，所有获许可的外汇银行须通过外汇信息系统（FEIS）提交报告。
