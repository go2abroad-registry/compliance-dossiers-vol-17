Ein virtueller Büroort kann rechtlich als Hauptsitz der Geschäftstätigkeit eingetragen werden, sofern er eine tatsächliche Adresse ist, die rechtliche Verfahren empfangen kann. Dennoch werden lokale Steuerbehörden und kommerzielle Banken normalerweise einen kommerziellen Postfach als einzigen Geschäftssitz für einen MedTech-Regulierungsberater ablehnen. Die nationale Steuerbehörde verlangt als Voraussetzung für die Eintragung von Umsatzsteuerrechnungen und die Firmensteuerstatus eine Beweisführung eines physischen Arbeitsplatzes, eines firmeneigenen Mietvertrags sowie von auf der Stelle befindlichen Ausrüstung; Banken erfordern dieselben Voraussetzungen für die Eröffnung eines Kontos. Für eine ausländische nicht ansässige Einheit, die eine koreanische Steuerpräsenz erlangt (durch einen festen Geschäftssitz oder durch Erzielung von koreanischen steuerpflichtigen Einkünften), muss die Einheit zunächst eine Registrierung für ausländische Investitionen oder die Bestellung eines inländischen Steuervertreters vornehmen, bevor jegliche steuerpflichtige Tätigkeit beginnt. Die Einheit (oder ihr Vertreter) muss eine Antrag auf Geschäftseröffnung (사업자등록신청서) an das zuständige Bezirkssteueroffizium (세무서) innerhalb der Zuständigkeit des Nationalen Steueramts (NTS) stellen. Erforderliche Unterlagen umfassen: eine amtlich bestätigte Kopie des Gründungsbeschlusses, Nachweise über Eigentum oder Mietverhältnis des koreanischen Geschäftssitzes (falls vorhanden), die Gesellschaftsordnung sowie eine apostillierte oder notarielle Vollmacht im Sinne des inländischen Steuervertreters. Nach Genehmigung verleiht das NTS eine 10-stellige Geschäftseröffnungsnummer (사업자등록번호), die sowohl die Steueridentifikationsnummer (TIN) als auch die MwSt-Registrierungsnummer darstellt. Für ausländische Einheiten ohne koreanischen Sitz, die jedoch koreanische Steuern abzuziehen haben, erhält das NTS über das gleiche HomeTax-Portal eine Abzugssteuer-Registrierungsnummer (원천징수용 고유번호). Im Hinblick auf die MwSt müssen alle ausländischen Lieferanten, die koreanische steuerpflichtige Leistungen erbringen, unabhängig von ihrem Umsatz über das vereinfachte Registrierungsverfahren (간이과세자 등록 oder 일반과세자 사업자 등록) zur MwSt-Registrierung berechtigt sein; eine ausländische Einheit, die ausschließlich auf Nullsteuer basiert, kann optional zur Beantragung von MwSt-Rückerstattungen registriert werden.
